Частица 만 — «только»

조사 만 [man]
Как сказать «только» по-корейски: маленькая частица, которая меняет смысл предложения

1. Что такое частица 만?

Частица 만 [man] означает «только», «лишь». Она ставится после существительного и ограничивает его — показывает, что речь идёт исключительно об этом предмете, человеке или времени.

Проще говоря: добавили 만 к слову — получилось «только это слово, и больше ничего».
나 만
[наман]
только я
하나 만
[ханаман]
только один

2. Как использовать: слово + 만

Формула очень простая. Просто берёте слово, которое хотите ограничить, и прибавляете 만 в конце — без пробела.

существительное + 만

Визуальная схема:

существительное
+
만
Корейский Произношение Перевод 🔈
나만 [наман] только я
하나만 [ханаман] только один
물만 [мульман] только воду
한국어만 [хангугоман] только корейский
커피만 [кхопхиман] только кофе
너만 [номан] только тебя

3. 만 заменяет или комбинируется с частицами

Это важный момент! В корейском много падежных частиц (은/는, 이/가, 을/를, 에). Когда добавляем 만, правила меняются:

Правило 1 — заменяет 은/는 и 이/가:
Подлежащие частицы исчезают, когда появляется 만.
• 저만 알아요 — только я знаю
• НЕ говорим: 저는만, 저만은 — это ошибка!
Правило 2 — можно (но не нужно) с 을/를:
Объектные частицы можно оставлять, но чаще их опускают.
• 물만 마셔요 — пью только воду (обычно так)
• 물만을 마셔요 — тоже можно, но звучит избыточно
Правило 3 — с 에 сохраняется:
Частица места/времени 에 остаётся, 만 ставится после неё.
• 집에만 있어요 — сижу только дома
• 주말에만 쉬어요 — отдыхаю только по выходным
Запомните порядок: 은/는 и 이/가 — заменяются; 을/를 — убирается; 에 — остаётся перед 만.

4. Основные примеры в предложениях

Смотрите, как 만 работает в живой речи:

저만 한국어를 알아요.
[чоман хангугорыль арайо]
Только я знаю корейский.
김치만 좋아해요.
[кимчхиман чоаэйо]
Люблю только кимчи.
주말에만 쉬어요.
[чумалеман щвиойо]
Отдыхаю только по выходным.
한 번만 보여 주세요.
[хан бономан поё чусейо]
Покажите только один раз, пожалуйста.
너만 사랑해요.
[номан саранхэйо]
Люблю только тебя.
오늘만 공부해요.
[онылман конбуэйо]
Учусь только сегодня.

5. 만 + 있다 / 없다

Частица 만 прекрасно сочетается с глаголами 있다 («есть, быть») и 없다 («нет, отсутствовать»). Это один из самых частых паттернов.

저만 있어요 → только я есть / только я остался
이것만 없어요 → только этого нет
시간만 있어요 → есть только время (денег нет)
돈만 없어요 → только денег нет
Совет: Эти конструкции часто используются, когда нужно подчеркнуть, что «всё есть, кроме» или «никого нет, кроме меня».

6. 만 с глаголами: -기만 하다 (продвинутое)

Частицу 만 можно добавлять и к глаголам — через форму -기만 하다. Это уже ближе к 2급, но для общего понимания полезно знать, что такая конструкция существует.

основа глагола + 기만 하다
먹기만 해요 → только и делает, что ест
자기만 해요 → только и делает, что спит
На уровне 1급: пока достаточно уметь использовать 만 с существительными. К форме -기만 하다 вернёмся на следующем уровне.

7. Частая ошибка: не путайте с 단 и 오직

В корейском есть ещё слова со значением «только», но они используются иначе:

Слово Значение Где используется
만 только (частица) Самое частое, везде в разговоре
단 [dan] лишь, один (числительное) 단 한 번 — всего один раз
오직 [ojik] исключительно (наречие) Формально, в книгах
Для уровня 1급: используйте только 만. Это самый простой и универсальный вариант.

8. Мини-диалог: В кафе

종업원 (официант):
어서 오세요. 뭘 드릴까요?
Добро пожаловать. Что вам принести?
손님 (гость):
커피만 주세요.
Только кофе, пожалуйста.
종업원:
케이크는요?
А торт?
손님:
아니요, 오늘은 커피만 마셔요.
Нет, сегодня пью только кофе.
종업원:
사이즈는요?
А размер?
손님:
작은 거 하나만 주세요.
Дайте только один маленький.
Обратите внимание: 만 ставится прямо после существительного, без пробела. В диалоге это 커피만 и 하나만.
