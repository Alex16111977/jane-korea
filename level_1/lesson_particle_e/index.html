Урок 18 · 1급 (A1)

Частица места 에 — нахождение

장소 조사 에 — 위치

1. Что такое 에?

Частица 에 указывает на место, где что-то находится, или время, когда что-то происходит. Это одна из самых важных частиц корейского языка.

Главное правило: 에 используется со статичными глаголами (있다, 없다, 살다), когда мы говорим о местоположении.

[место] + 에 + 있다 / 없다 / 살다
Место + 에 + быть / не быть / жить
집에 있어요 [jibe isseoyo] Нахожусь дома
학교에 있어요 [hakgyoe isseoyo] Нахожусь в школе
한국에 살아요 [hanguge sarayo] Живу в Корее
카페에 없어요 [kapee eopseoyo] Нет в кафе / Меня нет в кафе

2. Примеры с местами

에 можно использовать с любым существительным, обозначающим место:

도서관에 있어요 [doseogwane isseoyo] Нахожусь в библиотеке
공원에 있어요 [gongwone isseoyo] Нахожусь в парке
서울에 살아요 [seoure sarayo] Живу в Сеуле
방에 있어요 [bange isseoyo] Нахожусь в комнате
병원에 있어요 [byeongwone isseoyo] Нахожусь в больнице
회사에 없어요 [hoesae eopseoyo] Нет на работе / Меня нет на работе

3. 에 как направление

Частица 에 также обозначает направление движения (куда?):

[место] + 에 + 가다 / 오다
Место + 에 + идти / приходить
학교에 가요 [hakgyoe gayo] Иду в школу
집에 와요 [jibe wayo] Прихожу домой
한국에 가요 [hanguge gayo] Еду в Корею

4. Разница: 에 vs 에서

Это одна из самых частых ошибок! Запомните:

에 = статичное местоположение (где находится?) / направление (куда?)
에서 = место действия (где делает что-то?)
에 (нахождение) vs 에서 (действие)
에 (статика)
에서 (действие)
Разница
학교에 있어요
학교에서 공부해요
В школе (нахожусь) vs В школе (учусь)
카페에 있어요
카페에서 커피를 마셔요
В кафе (нахожусь) vs В кафе (пью кофе)
집에 있어요
집에서 요리해요
Дома (нахожусь) vs Дома (готовлю)
도서관에 있어요
도서관에서 책을 읽어요
В библиотеке (нахожусь) vs В библиотеке (читаю)
Простое правило:
있다 / 없다 / 살다 / 가다 / 오다 → 에
Все остальные глаголы (делать что-то) → 에서

5. 에 для обозначения времени

Частица 에 также используется для указания времени (когда?):

월요일에
В понедельник
3시에
В 3 часа
아침에
Утром
저녁에
Вечером
주말에
На выходных
여름에
Летом
월요일에 학교에 가요 [woryoire hakgyoe gayo] В понедельник иду в школу
아침에 커피를 마셔요 [achime keopireul masyeoyo] Утром пью кофе
저녁에 집에 와요 [jeonyeoge jibe wayo] Вечером прихожу домой
Исключение: со словами 오늘 (сегодня), 어제 (вчера), 내일 (завтра), 지금 (сейчас) частица 에 НЕ используется!
오늘 학교에 가요. (Сегодня иду в школу.) — НЕ "오늘에"

6. Мини-диалог: В кафе

민수 (Мину):
지금 어디에 있어요?
Где ты сейчас?
어디 + 에 = где
수진 (Суджин):
카페에 있어요.
Я в кафе.
카페 + 에 = в кафе
민수:
어느 카페에 있어요?
В каком кафе?
어느 = какой, который
수진:
학교 앞에 있는 카페에 있어요.
В кафе перед школой.
앞 + 에 = перед
민수:
좋아요! 저도 지금 그 카페에 갈게요.
Хорошо! Я тоже сейчас приду в то кафе.
카페 + 에 = в кафе (направление)
수진:
네, 빨리 오세요!
Да, приходи скорей!

7. Упражнения

Выберите правильную частицу: 에 или 에서?

1. 집___ 있어요. (Я дома.)

2. 도서관___ 책을 읽어요. (Читаю книгу в библиотеке.)

3. 한국___ 살아요. (Живу в Корее.)

4. 카페___ 커피를 마셔요. (Пью кофе в кафе.)

5. 학교___ 가요. (Иду в школу.)

6. 회사___ 일해요. (Работаю на работе.)

7. 방___ 없어요. (Нет в комнате.)

8. 공원___ 운동해요. (Занимаюсь спортом в парке.)
