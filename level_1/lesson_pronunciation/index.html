Правила произношения

발음 규칙 — Как буквы меняют звук
Корейский пишется одним способом, а произносится часто иначе. Изучаем пять главных правил изменения звуков

1. Озвончение (유성음화)

Согласные ㄱ, ㄷ, ㅂ, ㅈ звучат глухо в начале слова, но озвончаются (становятся мягче) между двумя звонкими звуками — то есть внутри слова между гласными или после звонкого согласного.

Правило озвончения:
гласная + [ㄱ/ㄷ/ㅂ/ㅈ] + гласная → [г/д/б/дж]
가다 → [gada] идти — "д" между гласными озвончается
바다 → [bada] море — ㅂ в начале слова звучит как мягкий [б], а не [п]
자다 → [jada] спать — второй ㄷ произносится как [д]
학교 → [hakkyo] школа — ㄱ после 받침 не озвончается!
Согласный В начале слова Между гласными Пример
ㄱ [к] [г] 아기 [agi] — ребёнок
ㄷ [т] [д] 아다 [ada]
ㅂ [п] [б] 아버지 [aboji]
ㅈ [ч] [дж] 아저씨 [ajossi]

2. Назализация (비음화)

Когда взрывной согласный (ㄱ, ㄷ, ㅂ) оказывается перед носовым (ㄴ, ㅁ), он сам становится носовым. Это происходит на стыке слогов.

Правила назализации:
ㄱ + ㄴ → ㅇ + ㄴ
ㄷ + ㄴ → ㄴ + ㄴ
ㅂ + ㄴ → ㅁ + ㄴ
한국말 → [hangungmal] корейский язык: ㄱ+ㅁ → ㅇ+ㅁ
십만 → [simman] 100 000: ㅂ+ㅁ → ㅁ+ㅁ
작년 → [jangnyeon] прошлый год: ㄱ+ㄴ → ㅇ+ㄴ
국민 → [gungmin] народ, гражданин: ㄱ+ㅁ → ㅇ+ㅁ

Почему так происходит? При произношении носового звука мягкое нёбо опускается. Когда следующий звук носовой, предыдущий согласный тоже "подстраивается" — воздух начинает выходить через нос раньше.

3. Аспирация — придыхание (격음화)

Когда согласный ㄱ, ㄷ, ㅂ или ㅈ встречается с ㅎ (в любом порядке), они сливаются в один придыхательный звук — с сильным выдохом воздуха.

Правила аспирации:
ㄱ + ㅎ (или ㅎ + ㄱ) → ㅋ
ㄷ + ㅎ (или ㅎ + ㄷ) → ㅌ
ㅂ + ㅎ (или ㅎ + ㅂ) → ㅍ
ㅈ + ㅎ (или ㅎ + ㅈ) → ㅊ
좋다 → [조타] [jota] хороший: ㅎ+ㄷ → ㅌ
않다 → [안타] [anta] не делать: ㄴ+ㅎ+ㄷ → ㄴ+ㅌ
입학 → [이팍] [ipak] поступление: ㅂ+ㅎ → ㅍ
축하 → [추카] [chuka] поздравление: ㄱ+ㅎ → ㅋ
Комбинация Результат Пример Произношение
ㄱ + ㅎ ㅋ [k'] 각하 [gaka] [가카]
ㄷ + ㅎ ㅌ [t'] 좋다 [jota] [조타]
ㅂ + ㅎ ㅍ [p'] 입히다 [ipida] [이피다]
ㅈ + ㅎ ㅊ [ch'] 맞히다 [machida] [마치다]

4. Оглушение конечного согласного (음절의 끝소리 규칙)

В корейском языке конечный согласный слога (받침 [batchim]) произносится в ослабленной форме — только 7 звуков могут стоять на конце слога: [к], [н], [т], [л], [м], [п], [нг].

Написание (받침) Произносится как Пример Транскрипция
ㄱ, ㅋ, ㄲ [к] 학 (학교) [хак]
ㄴ [н] 한국 [хан-гук]
ㄷ, ㅅ, ㅆ, ㅈ, ㅊ, ㅌ, ㅎ [т] 있다 [itda] [иттa]
ㄹ [л] 말 [mal] [мал]
ㅁ [м] 봄 [bom] [бом]
ㅂ, ㅍ [п] 앞 [ap] [ап]
ㅇ (в конце) [нг] 강 [gang] [ганг]
Важно: Когда после слога с 받침 идёт слог, начинающийся на ㅇ (немой начальный), конечный согласный "перетекает" на следующий слог: 학교 = 학+교 → [hak-gyo], но 학원 = 학+원 → [ha-gwon].
Удвоение согласного (경음화):
Когда конечный согласный одного слога встречает начальный согласный следующего слога, часто происходит "усиление" — согласный становится напряжённым:
학교 → [hak-kyo] школа: ㄱ+ㄱ → сильное [кк]
국제 → [kuk-jje] международный: ㄱ+ㅈ → ㄲ+ㅈ

5. Правила произношения ㄹ

Согласный ㄹ — один из самых интересных в корейском. Он меняется в зависимости от соседних звуков и позиции.

ㄹ рядом с ㄴ → оба становятся ㄹ (ллиализация):
ㄴ + ㄹ → ㄹ + ㄹ
ㄹ + ㄴ → ㄹ + ㄹ
설날 → [설랄] [seollal] Новый год по лунному календарю: ㄹ+ㄴ → ㄹ+ㄹ
신라 → [실라] [silla] Силла (историческое государство): ㄴ+ㄹ → ㄹ+ㄹ
한라산 → [할라산] [hallasan] гора Халласан: ㄴ+ㄹ → ㄹ+ㄹ
Позиция ㄹ Произношение Описание Пример
Между гласными [р] — звонкий Мягкий, похож на "р" 아름답다 [areumdapda]
В конце слога (받침) [л] Как русское "л" 말 [mal] — слово
ㄹ + ㄴ [лл] ㄴ переходит в ㄹ 설날 [seollal]
ㄴ + ㄹ [лл] ㄴ переходит в ㄹ 신라 [silla]
ㄹ в начале слова [н] или [р] Часто заменяется на ㄴ в родных словах 라디오 [radio] — заимств.
Исключение — начало слова: В исконно корейских словах ㄹ не стоит в начале слова. В заимствованных (радио, ресторан и т.п.) — стоит: 라디오 [radio], 레스토랑 [reseutorang].
