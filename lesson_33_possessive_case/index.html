Урок 8

Притяжательный падеж 의

🏠 Что такое притяжательный падеж?

Отвечает на вопрос "ЧЕЙ? ЧЬЯ? ЧЬЁ?"

Показывает принадлежность и владение

Чья книга? Чей дом? Чьё имя?

📝 Простая формула

владелец + 의 + предмет

🎯 Основная структура

지민이의 책 = книга Чимина

엄마의 가방 = мамина сумка

우리의 집 = наш дом

👨‍👩‍👧‍👦 Семья и родственники

아버지의 차 папина машина 아버지 + 의 (папы) + 차 (машина)
언니의 핸드폰 телефон старшей сестры 언니 + 의 (старшей сестры) + 핸드폰 (телефон)
할머니의 집 дом бабушки 할머니 + 의 (бабушки) + 집 (дом)

👥 Друзья с корейскими именами

민수의 책가방 рюкзак Минсу 민수 + 의 (Минсу) + 책가방 (рюкзак)
서연의 강아지 собачка Соён 서연 + 의 (Соён) + 강아지 (собачка)
준호의 자전거 велосипед Чунхо 준호 + 의 (Чунхо) + 자전거 (велосипед)
하영의 노트북 ноутбук Хаён 하영 + 의 (Хаён) + 노트북 (ноутбук)

🗣️ Произношение 의

의 может произноситься по-разному!

📖 В официальной речи

[ый]

지민의 책 → [지민의 책] (четко)

🗨️ В быстрой разговорной речи

[에]

지민의 책 → [지민에 책] (быстро)

✂️ Важно! 의 можно убирать!

В разговорной речи 의 часто опускается

С 의 (формально)

지민이의 책
книга Чимина

Без 의 (разговорно)

지민이 책
книга Чимина

🎯 Больше примеров:

수연이의 고양이 → 수연이 고양이 (кошка Суён)

아빠의 회사 → 아빠 회사 (папина компания)

우리의 학교 → 우리 학교 (наша школа)

🎒 Школа и учёба

성민이 연필 карандаш Сонмина 성민이 (Сонмина) + 연필 (карандаш) - без 의!
예슬의 숙제 домашнее задание Есыль 예슬 + 의 (Есыль) + 숙제 (домашнее задание)
건우 가방 сумка Гону 건우 (Гону) + 가방 (сумка) - без 의!

🏢 Работа и профессии

선생님의 책상 стол учителя 선생님 + 의 (учителя) + 책상 (стол)
의사 선생님 병원 больница доктора 의사 선생님 (доктора) + 병원 (больница) - без 의!
미용사의 가위 ножницы парикмахера 미용사 + 의 (парикмахера) + 가위 (ножницы)

⚠️ Важные особенности

1. С местоимениями:
나의 → 내 (мой/моя)
너의 → 네 (твой/твоя)
우리의 → 우리 (наш/наша)
2. Разговорная речь:
의 очень часто убирается!
지민이의 책 = 지민이 책
3. Произношение:
의 → [ый] или [에] в быстрой речи

💪 Проверь себя!

1. Как сказать "машина Минджи"?
민지 + ? + 차
2. Можно ли сказать "엄마 가방" вместо "엄마의 가방"?
3. "Это дом Чанмина" = ?
이것은 + ? + 집이에요
4. Как произносится "지원의" в быстрой речи?
Ответы:
1. 민지의 차 или просто 민지 차
2. Да! В разговорной речи это нормально
3. 이것은 찬민의 집이에요 (или 찬민 집이에요)
4. [지원에] - 의 произносится как [에]
