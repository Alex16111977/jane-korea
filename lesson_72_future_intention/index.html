Урок 12

Намерение и воля -겠-

💪 Суффикс -겠-

-겠- = СОБИРАЮСЬ, НАМЕРЕН

Основа глагола + 겠 + окончание

Выражает намерение или волеизъявление говорящего

🎯 Что выражает -겠-

💭 Намерение

내일 한국어를 공부하겠어요 - Завтра собираюсь изучать корейский

Мое твердое намерение что-то делать

💪 Волеизъявление

담배를 끊겠어요 - Брошу курить

Выражение твердой воли, решимости

📋 Планы

친구를 만나겠어요 - Собираюсь встретить друга

Рассказ о своих планах на будущее

📝 Как образуется

1

Берем основу глагола

그만두다 → 그만두 | 가다 → 가 | 공부하다 → 공부하

2

Добавляем -겠-

그만두 + 겠 | 가 + 겠 | 공부하 + 겠

3

Добавляем окончание

그만두겠어요 | 가겠어요 | 공부하겠어요

📚 Планы на учебу

내일 한국어를 공부하겠어요 Завтра собираюсь изучать корейский язык 공부하다 → 공부하겠어요
영화를 보러 가겠어요 Собираюсь пойти смотреть кино 가다 → 가겠어요
사무실에서 기다리겠어요 Буду ждать в офисе 기다리다 → 기다리겠어요

💪 Твердые решения

신정까지 담배를 끊겠어요 К Новому году брошу курить 끊다 → 끊겠어요
잘 먹겠습니다 Приятного аппетита (я хорошо поем) 먹다 → 먹겠습니다 (устойчивое выражение)
언제 이사하겠어요? Когда собираетесь переезжать? 이사하다 → 이사하겠어요

⚠️ Важное ограничение!

-겠- используется ТОЛЬКО с 1-м и 2-м лицом!

✅ ПРАВИЛЬНО

제가 하겠어요

(Я сделаю - 1-е лицо)

언제 가겠어요?

(Когда пойдете? - 2-е лицо)

❌ НЕПРАВИЛЬНО

민호가 하겠어요

(Минхо сделает - звучит странно!)

Use: 민호가 할 거예요

💡 Для 3-го лица используйте -(으)ㄹ 거예요

🚫 Отрицательные формы

С 안 (обычное отрицание)

안 하겠어요 - Не буду делать

안 가겠어요 - Не пойду

С -지 않겠어요 (формальное отрицание)

하지 않겠어요 - Не буду делать

가지 않겠어요 - Не пойду

🚫 Отказы и нежелание

청소를 안 하겠어요 Не собираюсь делать уборку 하다 → 안 하겠어요
그런 책은 더 이상 읽지 않겠어요 Такие книги больше читать не собираюсь 읽다 → 읽지 않겠어요
그 영화는 안 보겠어요 Тот фильм не собираюсь смотреть 보다 → 안 보겠어요
오늘 학교에 가지 않겠어요 Сегодня в школу не собираюсь идти 가다 → 가지 않겠어요

💔 Решительные разрывы

그 사람과 더 이상 만나지 않겠어요 С этим человеком больше не буду встречаться 만나다 → 만나지 않겠어요
이제 그만두겠어요 Теперь брошу это 그만두다 → 그만두겠어요

🍽️ Еда и напитки

잘 먹겠습니다 Приятного аппетита Устойчивое выражение благодарности перед едой
커피를 마시겠어요 Буду пить кофе 마시다 → 마시겠어요
오늘은 한식을 먹겠어요 Сегодня буду есть корейскую еду 먹다 → 먹겠어요

🏃 Повседневные планы

일찍 일어나겠어요 Встану рано 일어나다 → 일어나겠어요
운동을 시작하겠어요 Начну заниматься спортом 시작하다 → 시작하겠어요
열심히 일하겠어요 Буду усердно работать 일하다 → 일하겠어요

💪 Потренируемся!

1. Как сказать "Завтра начну изучать корейский"?
Подсказка: 내일 + 시작하다 + 겠어요
2. "Больше курить не буду" = ?
Подсказка: 더 이상 + 피우다 + отрицание + 겠어요
3. Почему нельзя сказать "지훈이 가겠어요"?
4. Ответьте на вопрос: "뭐 드시겠어요?" (кофе)
Ответы:
1. 내일 한국어 공부를 시작하겠어요
2. 더 이상 담배를 피우지 않겠어요
3. -겠- используется только с 1-м и 2-м лицом
4. 커피를 마시겠어요

📝 Главное правило!

-겠- = МОЕ намерение, воля (только 1-е и 2-е лицо)

Образование: основа глагола + 겠 + окончание

Отрицание: 안 + глагол + 겠어요 / -지 않겠어요

Ограничение: НЕ используется для 3-го лица

Для других: -(으)ㄹ 거예요 (обычное будущее время)
