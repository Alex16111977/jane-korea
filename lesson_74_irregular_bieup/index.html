Урок 14

Неправильные глаголы ㅂ-неправильные

⚡ ㅂ-неправильные глаголы

ㅂ исчезает и появляется 우/워

춥다 → 추워요 (ㅂ исчезает, появляется 워)

Простое правило: ㅂ "убегает" перед гласными и оставляет 우 или 워

❓ Простое объяснение

📏 Обычные глаголы

먹다 → 먹 + 어요 = 먹어요

Просто склеиваем основу с окончанием

⚡ ㅂ-неправильные

춥다 → 춥 становится 추우 + 어요 = 추워요

ㅂ "убегает" и оставляет 우. Потом 우 + 어 = 워

💡 Запомните: ㅂ "съедает", оставляя 우!

📝 Пошаговое правило

1

Найдите основу на ㅂ

춥다 → основа 춥 (заканчивается на ㅂ)

2

Убираем ㅂ, добавляем ㅜ

춥 → 추 + ㅜ = 추우 (новая основа)

3

Добавляем окончание

추우 + 어요 = 추워요 (ㅜ + ㅓ = ㅝ)

🎯 Ключ: ㅜ + ㅓ/ㅏ = ㅝ/ㅘ

ㅜ + ㅓ = ㅝ (как в 추워요) | ㅜ + ㅏ = ㅘ (как в 도와요)

🎯 Когда ㅂ меняется, а когда нет

Ключевое правило: смотрим на первую букву окончания!

✅ Окончание на ГЛАСНУЮ

ㅂ МЕНЯЕТСЯ

-어요, -았어요, -으면

춥다 → 추워요

❌ Окончание на СОГЛАСНУЮ

ㅂ НЕ МЕНЯЕТСЯ

-습니다, -지만

춥다 → 춥습니다

🌡️ Прилагательные (температура, ощущения)

오늘 날씨가 추워요 Сегодня погода холодная 춥다 → 춥 + 어요 → 추워요
여름이라서 더워요 Лето, поэтому жарко 덥다 → 덥 + 어요 → 더워요
이 문제는 쉬워요 Эта задача легкая 쉽다 → 쉽 + 어요 → 쉬워요
무거운 짐이 무거워요 Тяжелый багаж тяжелый 무겁다 → 무겁 + 어요 → 무거워요

🤝 Глаголы действия

엄마를 도와요 Помогаю маме 돕다 → 돕 + 아요 → 도와요
누워서 쉬어요 Лежу и отдыхаю 눕다 → 눕 + 어요 → 누워요
빵을 구워요 Пеку хлеб 굽다 → 굽 + 어요 → 구워요
쓰레기를 주워요 Подбираю мусор 줍다 → 줍 + 어요 → 주워요

⏰ Прошедшее время

어제 추웠어요 Вчера было холодно 춥다 → 춥 + 었어요 → 추웠어요
친구를 도왔어요 Помог другу 돕다 → 돕 + 았어요 → 도왔어요
시험이 어려웠어요 Экзамен был трудным 어렵다 → 어렵 + 었어요 → 어려웠어요

📏 С согласными (ㅂ НЕ меняется)

날씨가 춥습니다 Погода холодная (формально) 춥다 + 습니다 → 춥습니다 (ㅂ не меняется)
춥지만 괜찮아요 Холодно, но нормально 춥다 + 지만 → 춥지만 (ㅂ не меняется)
덥지 않아요 Не жарко 덥다 + 지 않아요 → 덥지 않아요

⚠️ Исключения из правила!

НЕ все слова на ㅂ - неправильные!

❌ Эти слова НЕ меняются:

좁다 (узкий) → 좁아요 (НЕ 조와요)

잡다 (ловить) → 잡아요 (НЕ 자와요)

입다 (надевать) → 입어요 (НЕ 이워요)

💡 Эти исключения нужно запомнить!

❌ Примеры исключений

이 방은 좁아요 Эта комната узкая 좁다 → 좁아요 (исключение, ㅂ не меняется)
공을 잡았어요 Поймал мяч 잡다 → 잡았어요 (исключение)
치마를 입었어요 Надела юбку 입다 → 입었어요 (исключение)

💪 Потренируемся!

1. Как сказать "Вчера было жарко"?
Подсказка: 덥다 + 었어요
2. "Помогаю маме готовить" = ?
Подсказка: 돕다 + 아요
3. Почему 좁다 → 좁아요, а не 조와요?
4. Переведите: "Этот багаж тяжелый, но я могу нести"
Ответы:
1. 어제 더웠어요
2. 엄마가 요리하는 것을 도와요
3. 좁다 - исключение из ㅂ-неправильного правила
4. 이 짐이 무거워요. 하지만 들 수 있어요

📝 Главное правило!

ㅂ-неправильные: ㅂ → ㅜ/ㅞ перед гласными

Гласное окончание: ㅂ меняется (춥다 → 추워요)

Согласное окончание: ㅂ не меняется (춥다 → 춥습니다)

Исключения: 좁다, 잡다, 입다 и другие

Запомните исключения - они НЕ следуют правилу!
