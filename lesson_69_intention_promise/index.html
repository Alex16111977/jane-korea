Урок 9

Намерение и обещание -(으)ㄹ게요

🤝 Конструкция -(으)ㄹ게요

-(으)ㄹ게요 = Я СДЕЛАЮ, Я БУДУ

Основа глагола + (으)ㄹ게요

Выражает намерение, клятву или обещание говорящего что-то делать в будущем

💭 Когда используем -(으)ㄹ게요

🤝 Обещание

도와줄게요 - Я помогу (обещаю помочь)

💪 Намерение

열심히 공부할게요 - Я буду усердно учиться

🙋 Предложение

제가 할게요 - Я сделаю (предлагаю сделать сам)

📝 Как образуется конструкция

1

Основа + согласная → -을게요

먹다 → 먹 + 을게요 = 먹을게요

2

Основа + гласная/ㄹ → -ㄹ게요

보다 → 보 + ㄹ게요 = 볼게요

열다 → 여 + ㄹ게요 = 열게요

🔄 Примеры спряжения

Глагол
Основа
-(으)ㄹ게요
먹다 (есть)
먹 (согласная)
먹을게요
보다 (смотреть)
보 (гласная)
볼게요
열다 (открывать)
여 (ㄹ → исчезает)
열게요
하다 (делать)
하 (гласная)
할게요

🤝 Обещания и клятвы

꼭 할게요 Обязательно сделаю 하다 → 하 + ㄹ게요
내일 일찍 올게요 Завтра приду пораньше 오다 → 오 + ㄹ게요
학교 앞에서 기다릴게요 Я подожду перед школой 기다리다 → 기다리 + ㄹ게요
도와줄게요 Я помогу 도와주다 → 도와주 + ㄹ게요

📞 Повседневные обещания

전화하면 받을게요 Если позвонишь, подниму трубку 받다 → 받 + 을게요
지금 확인할게요 Сейчас проверю 확인하다 → 확인하 + ㄹ게요
바로 보낼게요 Отправлю прямо сейчас 보내다 → 보내 + ㄹ게요
시장에 갈게요 Я пойду на рынок 가다 → 가 + ㄹ게요

📚 Учеба и работа

열심히 공부할게요 Я буду много заниматься 공부하다 → 공부하 + ㄹ게요
내일은 안 잊을게요 Завтра не забуду 잊다 → 잊 + 을게요
서류를 팩스로 보낼게요 Отправлю документы по факсу 보내다 → 보내 + ㄹ게요
제가 먼저 갈게요 Я пойду первым 가다 → 가 + ㄹ게요

⚠️ Важное ограничение!

-(으)ㄹ게요 ТОЛЬКО для говорящего!

✅ ПРАВИЛЬНО

제가 할게요

(Я сделаю)

❌ НЕПРАВИЛЬНО

지훈이 할게요

(Джихун сделает - так не говорят!)

💡 Запомните: Можно говорить только о своих намерениях!

Для других людей используйте будущее время: 지훈이 할 거예요

🍽️ Еда и угощение

잘 먹을게요 Спасибо за еду (перед едой) Устойчивое выражение благодарности
더 먹을게요 Буду есть еще 먹다 → 먹 + 을게요
물을 마실게요 Воды попью 마시다 → 마시 + ㄹ게요

🎯 Решения и планы

이번에는 성공할게요 На этот раз добьюсь успеха 성공하다 → 성공하 + ㄹ게요
다시 시작할게요 Начну заново 시작하다 → 시작하 + ㄹ게요
조심할게요 Буду осторожен 조심하다 → 조심하 + ㄹ게요

💪 Потренируемся!

1. Как сказать "Я открою дверь"?
Подсказка: 열다 + -(으)ㄹ게요
2. "Буду усердно изучать корейский" = ?
Подсказка: 열심히 한국어를 공부하다
3. Почему нельзя сказать "친구가 올게요"?
4. Ответьте на вопрос: "누가 해요?" (Кто будет делать?)
Ответы:
1. 문을 열게요
2. 열심히 한국어를 공부할게요
3. -(으)ㄹ게요 используется только для говорящего
4. 제가 할게요 (Я сделаю)

📝 Главное правило!

-(으)ㄹ게요 = МОЕ намерение, обещание

Согласная + 을게요: 먹을게요, 받을게요

Гласная/ㄹ + ㄹ게요: 볼게요, 할게요, 열게요
