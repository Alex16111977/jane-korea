Каузатив (사동사)

사동사: 누군가에게 무엇을 하게 하다 [sadonsa: nugungaege mueoseul hage hada]
Заставляем, позволяем, побуждаем: 먹이다, 웃기다, 울리다, 살리다

Что такое каузатив?

Каузатив - это когда субъект не делает действие сам, а заставляет, побуждает или позволяет кому-то другому это сделать.

В русском языке это похоже на: "кормить" (заставлять есть), "смешить" (заставлять смеяться), "будить" (заставлять проснуться).

В корейском каузатив образуется двумя способами:

  1. Суффиксальный каузатив - добавление суффиксов 이, 히, 리, 기, 우, 추 к основе глагола
  2. Аналитический каузатив - конструкция -게 하다 (более универсальная)

В этом уроке мы изучим оба способа.

Суффиксальный каузатив: 6 суффиксов

Нет четкого правила, какой суффикс добавлять к какому глаголу - их нужно запоминать. Но есть определенные закономерности.

-이- [i]
먹다 -> 먹이다
есть -> кормить
보다 -> 보이다
видеть -> показывать
죽다 -> 죽이다
умирать -> убивать
-히- [hi]
읽다 -> 읽히다
читать -> дать прочитать
앉다 -> 앉히다
сидеть -> усадить
입다 -> 입히다
одевать(ся) -> одеть кого-то
-리- [ri]
울다 -> 울리다
плакать -> довести до слез
살다 -> 살리다
жить -> спасти (оживить)
알다 -> 알리다
знать -> сообщить
-기- [gi]
웃다 -> 웃기다
смеяться -> смешить
벗다 -> 벗기다
раздеваться -> раздеть
남다 -> 남기다
оставаться -> оставить
-우- [u]
자다 -> 재우다
спать -> уложить спать
깨다 -> 깨우다
проснуться -> разбудить
타다 -> 태우다
ехать -> посадить (в транспорт)
-추- [chu]
낮다 -> 낮추다
быть низким -> понизить
맞다 -> 맞추다
совпадать -> подогнать, сверить

Аналитический каузатив: -게 하다

Конструкция -게 하다 [ge hada] - это универсальный способ образования каузатива, который работает с любым глаголом. Она означает "сделать так, чтобы кто-то что-то делал".

Суффиксальный vs. аналитический каузатив:
  • Суффиксальный (먹이다, 웃기다) - звучит более естественно, но нужно запоминать формы
  • Аналитический (-게 하다) - работает с любым глаголом, более универсальный
  • Иногда значения немного отличаются: 웃기다 = "смешить" (активно), 웃게 하다 = "заставить смеяться" (более нейтрально)

Диалог: В детском саду

선생님 (Учитель):
아이들을 의자에 앉혔어요?
Вы усадили детей на стулья?
앉다 + 히 -> 앉히다 (усадить)
보조 (Помощник):
네, 앉히고 밥도 먹였어요.
Да, усадил(а) и накормил(а) их.
먹다 + 이 -> 먹이다 (кормить)
선생님:
점심 후에 아이들을 재워야 해요.
После обеда нужно уложить детей спать.
자다 + 우 -> 재우다 (уложить спать)
보조:
알겠어요. 그런데 민준이가 다른 아이들을 자꾸 웃겨요.
Хорошо. Но Минджун всё время смешит других детей.
웃다 + 기 -> 웃기다 (смешить)
선생님:
민준이를 조용하게 해 주세요. 동화책을 읽히면 조용해질 거예요.
Сделайте так, чтобы Минджун был тихим. Если дать ему прочитать сказку, он успокоится.
조용하게 하다 (аналитический каузатив), 읽다 + 히 -> 읽히다

Каузатив vs. Пассив

Некоторые суффиксы каузатива совпадают с суффиксами пассива (이, 히, 리, 기). Различать их нужно по контексту.

Как отличить?
  • Каузатив: Субъект ЗАСТАВЛЯЕТ кого-то делать. 엄마가 아이에게 옷을 입혔어요. (Мама одела ребенка)
  • Пассив: Действие совершается НАД субъектом. 그 책이 많이 읽힌다. (Эту книгу много читают / Эта книга много читается)
  • Подсказка: в каузативе есть "заставитель" (кто заставляет) и "исполнитель" (кто делает). В пассиве - только тот, над кем совершается действие.

Заключение

Каузативные глаголы - важная часть корейской грамматики. Они позволяют выразить идею "заставлять" или "побуждать" кого-то к действию.
