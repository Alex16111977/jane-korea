Неправильные глаголы ㅅ-неправильные

✨ ㅅ-неправильные глаголы

ㅅ исчезает перед гласными!

쓰다 → 써요 (ㅅ выпадает!)

Простое правило: ㅅ "убегает" перед гласными, но остается перед согласными

🍳 Один глагол - разные значения

밥을 지어요 Готовлю рис 짓다 = готовить (еду)
집을 지어요 Строю дом 짓다 = строить
강아지에게 이름을 지었어요 Дали собачке имя 짓다 = давать имя
반찬을 저어요 Мешаю кашу 젓다 = мешать, размешивать

❓ Как работает правило

📝 Обычные глаголы

먹다 → 먹 + 어요 = 먹어요

Основа не меняется

✨ ㅅ-неправильные

쓰다 → 쓰 становится 써 + 요 = 써요

ㅅ "убегает", остается только основная гласная

💡 ㅅ боится гласных и исчезает!

📝 Пошаговое правило

1

Найдите основу на ㅅ

쓰다 → основа 쓰 (заканчивается на ㅅ)

2

Проверьте окончание

Начинается на гласную (어요, 아요) или согласную (습니다)?

3

Примените правило

Гласная → ㅅ выпадает: 쓰 + 어요 = 써요

Согласная → ㅅ остается: 쓰 + 습니다 = 씁니다

🎯 Когда ㅅ выпадает, а когда нет

Все зависит от первой буквы окончания!

✅ ГЛАСНАЯ = ㅅ ВЫПАДАЕТ

ㅅ ИСЧЕЗАЕТ

-어요, -아요, -었어요

쓰다 → 써요

❌ СОГЛАСНАЯ = ㅅ ОСТАЕТСЯ

ㅅ НЕ МЕНЯЕТСЯ

-습니다, -지만

쓰다 → 씁니다

✍️ Глаголы действия (письмо, строительство)

편지를 써요 Пишу письмо 쓰다 → 쓰 + 어요 → 써요 (ㅅ выпадает)
집을 지어요 Строю дом 짓다 → 짓 + 어요 → 지어요 (ㅅ выпадает)
물을 부어요 Наливаю воду 붓다 → 붓 + 어요 → 부어요 (ㅅ выпадает)
감기가 나았어요 Простуда прошла 낫다 → 낫 + 았어요 → 나았어요 (ㅅ выпадает)

⏰ Прошедшее время

어제 일기를 썼어요 Вчера писал дневник 쓰다 → 쓰 + 었어요 → 썼어요
새 건물을 지었어요 Построили новое здание 짓다 → 짓 + 었어요 → 지었어요
컵에 차를 부었어요 Налил чай в чашку 붓다 → 붓 + 었어요 → 부었어요

📏 С согласными (ㅅ НЕ выпадает)

매일 일기를 씁니다 Каждый день пишу дневник (формально) 쓰다 + 습니다 → 씁니다 (ㅅ не выпадает)
글씨를 쓰지만 못해요 Пишу, но плохо получается 쓰다 + 지만 → 쓰지만 (ㅅ не выпадает)
집을 짓지 않아요 Не строю дом 짓다 + 지 않아요 → 짓지 않아요

⚠️ Исключения из правила!

НЕ все слова на ㅅ - неправильные!

❌ Эти слова НЕ меняются:

웃다 (смеяться) → 웃어요 (НЕ 우어요)

씻다 (мыть) → 씻어요 (НЕ 시어요)

벗다 (снимать) → 벗어요 (НЕ 버어요)

빗다 (расчесывать) → 빗어요 (НЕ 비어요)

💡 Исключения нужно запомнить отдельно!

❌ Примеры исключений

아이들이 웃어요 Дети смеются 웃다 → 웃어요 (исключение, ㅅ не выпадает)
손을 씻었어요 Помыл руки 씻다 → 씻었어요 (исключение)
옷을 벗어요 Снимаю одежду 벗다 → 벗어요 (исключение)

📝 Главное правило!

ㅅ-неправильные: ㅅ выпадает перед гласными

Гласное окончание: ㅅ выпадает (쓰다 → 써요)

Согласное окончание: ㅅ остается (쓰다 → 씁니다)

Исключения: 웃다, 씻다, 벗다, 빗다

Запомните исключения - они НЕ следуют правилу!
