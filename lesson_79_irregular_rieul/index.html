Неправильные глаголы 르-неправильные

🔥 르-неправильные глаголы

ㅡ исчезает и ㄹ удваивается!

빠르다 → 빨라요 (르 → ㄹ + ㄹ)

Простое правило: 르 + 아/어 → ㄹ + 라/러 (ㅡ выпадает, ㄹ удваивается)

❓ Как работает правило

📏 Обычные глаголы

먹다 → 먹 + 어요 = 먹어요

Основа не меняется

🔥 르-неправильные

빠르다 → 빠르 + 아요 → 빨 + 라요 = 빨라요

ㅡ "убегает", а ㄹ удваивается

💡 르 → ㄹ + ㄹ (удваивание ㄹ!)

📝 Пошаговое правило

1

Найдите основу на 르

빠르다 → основа 빠르 (заканчивается на 르)

2

Убираем ㅡ, оставляем согласную

빠르 → 빠ㄹ (убираем гласную ㅡ из 르)

3

Добавляем окончание с удвоением ㄹ

빠ㄹ + 아요 = 빨라요 (ㄹ + ㄹ + 아요)

빠ㄹ + 어요 = 빨러요 (ㄹ + ㄹ + 어요)

🎯 Правило работает только с гласными

르 меняется только перед гласными 아/어!

✅ ГЛАСНЫЕ 아/어 = ИЗМЕНЕНИЕ

르 → ㄹ + ㄹ

빠르다 + 아요 = 빨라요

부르다 + 어요 = 불러요

❌ СОГЛАСНЫЕ = БЕЗ ИЗМЕНЕНИЙ

르 НЕ МЕНЯЕТСЯ

빠르다 + 지만 = 빠르지만

빠르다 + 습니다 = 빠릅니다

🏃 Примеры в действии

이 사람을 잘 몰라요 Плохо знаю этого человека 모르다 → 모르 + 아요 → 몰라요 (르 → ㄹ + ㄹ)
우리 의견이 달라요 У нас мнения отличаются 다르다 → 다르 + 아요 → 달라요
언니를 불렀어요 Позвала старшую сестру 부르다 → 부르 + 었어요 → 불렀어요
시간이 빨라요 Время быстро идет 빠르다 → 빠르 + 아요 → 빨라요

🌱 Больше примеров 르-неправильных

식물을 길러요 Выращиваю растения 기르다 → 기르 + 어요 → 길러요
빨래가 말랐어요 Белье высохло 마르다 → 마르 + 았어요 → 말랐어요
서둘러 주세요 Поторопитесь, пожалуйста 서두르다 → 서두르 + 어요 → 서둘러요
갑자기 떠올랐어요 Вдруг вспомнил 떠오르다 → 떠오르 + 았어요 → 떠올랐어요

📏 С согласными (르 НЕ меняется)

이 길이 빠릅니다 Эта дорога быстрая (формально) 빠르다 + 습니다 → 빠릅니다 (르 не меняется)
빠르지만 위험해요 Быстро, но опасно 빠르다 + 지만 → 빠르지만
잘 모르니까 물어볼게요 Не знаю хорошо, поэтому спрошу 모르다 + 니까 → 모르니까

💪 Потренируемся!

1. Как сказать "Не знаю этого человека"?
Подсказка: 모르다 + 아요
2. "Мнения отличаются" = ?
Подсказка: 다르다 + 아요
3. Как сказать "Позвал сестру"?
Подсказка: 부르다 + 었어요
4. Переведите: "빨리 서둘러 주세요"
5. Почему 빠르다 → 빠릅니다, а не 빨립니다?
6. "Выращиваю растения" = ?
Подсказка: 기르다 + 어요
Ответы:
1. 이 사람을 몰라요
2. 의견이 달라요
3. 언니를 불렀어요
4. Быстро поторопитесь, пожалуйста
5. Потому что -습니다 начинается на согласную, 르 не меняется
6. 식물을 길러요

📝 Главное правило!

르-неправильные: 르 + 아/어 → ㄹ + ㄹ + 아/어

Гласные 아/어: ㅡ выпадает, ㄹ удваивается

빠르다 + 아요 = 빨라요 (빠ㄹ + ㄹ + 아요)

Согласные: 르 не меняется (빠르다 + 지만 = 빠르지만)

Эти глаголы очень часто используются в разговоре!
