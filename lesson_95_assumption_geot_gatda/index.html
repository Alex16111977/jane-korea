Предположение -(으)ㄹ 것 같다

📖 Что мы изучаем

Разбираем конструкцию 것 같다 — главный способ сказать «кажется», «наверное», «по-моему». Форма перед 것 같다 меняется в зависимости от того, о чём вы догадываетесь: о будущем, настоящем или прошлом.

  • -(으)ㄹ 것 같다 — догадка о будущем: 비가 올 것 같아요
  • -는 것 같다 — догадка о том, что происходит сейчас (глаголы): 자는 것 같아요
  • -(으)ㄴ 것 같다 — о состоянии (прилагательные) и о прошлом (глаголы): 작은 것 같아요
  • Смягчает категоричность: вместо 작아요 вежливее сказать 작은 것 같아요

💬 Диалог урока

점원: 손님, 바지가 잘 맞으세요?

Продавец: Брюки хорошо сидят?

마이클: 아니요, 좀 큰 것 같아요. 더 작은 사이즈는 없어요?

Майкл: Нет, кажется, великоваты. Размера поменьше нет?

점원: 잠시만요. 이건 어떠세요?

Продавец: Минуточку. А эти как?

마이클: 이게 훨씬 낫네요. 이걸로 할게요.

Майкл: Эти намного лучше. Возьму их.

📚 Грамматическое объяснение

🔑 Почему корейцы всё время говорят 것 같다

것 같다 буквально значит «похоже на то, что…». Кореец редко скажет прямо «эта юбка короткая» — прозвучит как приговор. Вместо этого говорят 치마가 짧은 것 같아요 («юбка, кажется, коротковата»). Поэтому 것 같다 — это не только догадка, но и вежливое смягчение собственного мнения.

Раздел 1: -(으)ㄹ 것 같다 — догадка о будущем

Основа глагола или прилагательного + -(으)ㄹ 것 같다

После гласной или ㄹ — -ㄹ 것 같다, после согласной — -을 것 같다. Это предположение о том, что ещё не произошло.

오다 (идти — о дожде) → 올 것 같다 → 비가 올 것 같아요

кажется, пойдёт дождь

춥다 (холодно) → 추울 것 같다 → 내일은 추울 것 같아요

завтра, наверное, будет холодно

먹다 (есть) → 먹을 것 같다 → 다 못 먹을 것 같아요

кажется, я всё это не съем

Раздел 2: -는 것 같다 — о том, что происходит сейчас

Глагол и 있다/없다 + -는 것 같다

Форма на -는 используется только с глаголами: вы предполагаете, что действие идёт прямо сейчас.

자다 (спать) → 지금 자는 것 같아요

кажется, он сейчас спит

몸에 붙다 (облегать) → 몸에 좀 붙는 것 같아요

кажется, немного в обтяжку

재미있다 → 이 영화 재미있는 것 같아요

по-моему, этот фильм интересный

Раздел 3: -(으)ㄴ 것 같다 — состояние и прошлое

Прилагательное + -(으)ㄴ 것 같다 · глагол в прошедшем + -(으)ㄴ 것 같다

С прилагательными -(으)ㄴ 것 같다 описывает нынешнее состояние. С глаголами та же форма говорит о том, что действие уже случилось.

짧다 (короткий) → 치마가 너무 짧은 것 같아요

юбка, кажется, слишком короткая

크다 (большой) → 바지가 좀 큰 것 같아요

брюки, по-моему, великоваты

가다 (уйти) → 벌써 간 것 같아요

похоже, он уже ушёл

📝 Примеры использования

제 생각에는 내일 비가 올 것 같아요.

По-моему, завтра пойдёт дождь.

가: 내일 날씨가 어떨까요? 나: 글쎄요. 눈이 올 것 같아요.

— Какая завтра будет погода? — Даже не знаю. Кажется, пойдёт снег.

가: 영진 씨가 어제 왜 안 왔을까요? 나: 아파서 못 왔을 것 같아요.

— Почему Ёнджин вчера не пришёл? — Наверное, заболел и не смог.

이 색은 저에게 잘 안 어울리는 것 같아요. 좀 밝은 색으로 보여 주세요.

Кажется, этот цвет мне не идёт. Покажите что-нибудь посветлее.

📋 Краткое содержание

  • -(으)ㄹ 것 같다 — предположение о будущем: 올 것 같아요
  • -는 것 같다 — предположение о действии сейчас (только глаголы)
  • -(으)ㄴ 것 같다 — состояние (прилагательные) и прошедшее действие
  • О прошлом можно и так: -았/었을 것 같다 — 왔을 것 같아요
  • 것 같다 смягчает мнение — звучит вежливее прямого утверждения
