🔢 Корейские числа 11-99

После 10 в корейском начинается логичная система! Обе системы счисления следуют одинаковой логике.

📝 Формула образования чисел 11-99:

🇨🇳 Китайско-корейская:

십 (10) + 숫자

11 = 십일 (сип + иль)
25 = 이십오 (2×10 + 5)
99 = 구십구 (9×10 + 9)

🇰🇷 Исконно корейская:

열 (10) + 숫자

11 = 열하나 (ёль + хана)
25 = 스물다섯 (смул + тасот)
99 = 아흔아홉 (ахун + ахоп)

💡 Примеры составных чисел 21-99:

🇨🇳 Китайско-корейские:

21 = 이십일 (i-sib-il)
35 = 삼십오 (sam-sib-o)

72 = 칠십이 (chil-sib-i)
96 = 구십육 (gu-sib-yuk)

🇰🇷 Исконно корейские:

21 = 스물하나 (seumul-hana)

⚠️ Важно! Исконно корейские числа используются только до 99! После 100 - только китайско-корейские.

🔥 Большие числа в корейском

Корейские большие числа следуют китайско-корейской системе. Важно знать основные разряды!

🏗️ Структура больших чисел:

십 (10) → 백 (100) → 천 (1,000) → 만 (10,000) → 십만 (100,000) → 백만 (1,000,000) → 천만 (10,000,000) → 억 (100,000,000)

  • 만 (ман) - ключевая единица! 10,000 = одна "ман"
  • 억 (ок) - 100,000,000 (сто миллионов)
  • 조 (чо) - триллион (1,000,000,000,000)
  • Корейцы считают по 10,000, не по 1,000 как мы!

⚠️ Важно! Корейская логика счета:

🌍 Привычная логика:

12,345 = двенадцать тысяч триста сорок пять

🇰🇷 Корейская логика:

12,345 = 일만 (одна ман) 이천삼백사십오

Корейцы группируют по 10,000 (만), а не по 1,000!

📊 Порядковые числительные: первый, второй, третий...

🔢 Как образовать порядковые числительные:

Основная формула:

ЧИСЛО (исконно корейское) + 번째 (пхончхэ)

  • 번째 - основной суффикс для порядковых числительных
  • 째 - короткая форма (менее формальная)
  • 첫 번째 - особая форма для "первый"
  • Используются исконно корейские числа до 99

💡 Важные моменты:

  • 첫 번째 - особая форма! НЕ "한 번째"
  • Короткие формы: 둘째 (2-й), 셋째 (3-й), 넷째 (4-й) - менее формальные
  • В вопросах: 몇 번째? (который по счету?)
  • Позиция: 몇 번째 자리? (какое место по счету?)

⏰ Время по-корейски

📋 Правила выражения времени:

Основная формула:

ЧАСЫ (исконно корейские) + 시 + МИНУТЫ (китайско-корейские) + 분

Примеры:

  • 3:15 = 세 시 십오 분 (сэ си сибо пун)
  • 7:30 = 일곱 시 삼십 분 (ильгоп си самсип пун)
  • 12:00 = 열두 시 (йольду си)
