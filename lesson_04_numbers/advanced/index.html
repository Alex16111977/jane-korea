⭐ САМОЕ ВАЖНОЕ: 제일 (je-il)

Слово 제일 - это НЕ ТОЛЬКО "первый", но и "самый лучший/главный"!

  • 제일 좋다 - самый лучший
  • 제일 중요하다 - самый важный
  • 제일 먼저 - в первую очередь
  • 제일가는 - первоклассный

🚨 ВАЖНАЯ ОСОБЕННОСТЬ: 만 (10,000)

В корейском языке есть отдельное слово для 10,000 - 만 (man)!

Это отличается от европейских языков, где мы группируем по тысячам.

Примеры:

  • 25,000 = 이만 오천 (2만 + 5천)
  • 150,000 = 십오만 (15만)
  • 1,250,000 = 백이십오만 (125만)

⚡ Специальные правила и исключения

🎯 Правила для исконно корейских:

  • Сокращения при использовании со счетными словами:
    하나 → 한, 둘 → 두, 셋 → 세, 넷 → 네
  • Только до 99: после этого переключайтесь на китайско-корейские
  • Особые формы для круглых десятков: 스물, 서른, 마흔, 쉰...

🎯 Правила для китайско-корейских:

  • Группировка по 만 (10,000): думайте в единицах по 10,000
  • Опущение 일 (1): говорим 백, а не 일백 для 100
  • Обязательны для всех чисел 100+
  • Используются во всех формальных ситуациях

🎯 Когда какие использовать:

  • Время (часы): исконно корейские до 12
  • Время (минуты): китайско-корейские всегда
  • Возраст: исконно корейские до 99, потом китайско-корейские
  • Деньги: китайско-корейские всегда
  • Даты: китайско-корейские всегда
  • Количество предметов: исконно корейские до 99
