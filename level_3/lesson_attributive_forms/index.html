Атрибутивные формы глаголов

동사 관형형 -는, -(으)ㄴ, -(으)ㄹ
Определения с глаголами: "читающий человек", "прочитанная книга", "книга, которую прочитаю"

Что такое 관형형?

В русском языке мы можем превратить глагол в определение: читать → читающий человек, прочитать → прочитанная книга. В корейском языке для этого используются специальные окончания — 관형형 [gwanhyeonghyeong] (атрибутивные формы).

В отличие от русского, где причастия изменяются по родам, числам и падежам, в корейском всё проще — нужно лишь выбрать правильное окончание в зависимости от типа глагола и времени.

Ключевая идея: Атрибутивная форма ставится перед существительным и описывает его, как прилагательное. Порядок: глагол в атрибутивной форме + существительное.
Базовая структура
읽다 → 읽는 사람
[inneun saram]
читать → читающий человек
읽다 → 읽은 책
[ilgeun chaek]
читать → прочитанная книга
읽다 → 읽을 책
[ilgeul chaek]
читать → книга, которую прочитаю

Настоящее время: -는 (действие)

Для глаголов действия (동사) в настоящем времени используется окончание -는. Оно показывает, что действие происходит сейчас или регулярно.

-는
основа глагола + 는
Для всех глаголов действия в настоящем времени, независимо от последнего звука основы.
먹다 → 먹는 사람
есть → человек, который ест
가다 → 가는 길
идти → дорога, по которой идёшь
공부하다 → 공부하는 학생
учиться → учащийся студент
살다 → 사는 곳
жить → место, где живёшь (ㄹ выпадает!)
Внимание — ㄹ выпадает! Если основа глагола заканчивается на ㄹ, он выпадает перед -는: 살다 → 사는 (не 살는), 만들다 → 만드는 (не 만들는), 알다 → 아는 (не 알는).
Примеры в предложениях
지금 먹는 음식이 뭐예요?
[jigeum meongneun eumsigi mwoyeyo]
Что за еда, которую ты сейчас ешь?
제가 다니는 학교는 서울에 있어요.
[jega danineun hakgyoneun seoure isseoyo]
Школа, в которую я хожу, находится в Сеуле.

Настоящее время: -(으)ㄴ (описание)

Для описательных глаголов (형용사, прилагательных) в настоящем времени используется -(으)ㄴ. Это эквивалент русских прилагательных.

-ㄴ
основа на гласную + ㄴ
크다 → 큰 집
быть большим → большой дом
예쁘다 → 예쁜 꽃
быть красивым → красивый цветок
-은
основа на согласную + 은
작다 → 작은 가방
быть маленьким → маленькая сумка
좋다 → 좋은 날씨
быть хорошим → хорошая погода
Примеры в предложениях
작은 가방을 사고 싶어요.
[jageun gabangeul sago sipeoyo]
Хочу купить маленькую сумку.
재미있는 영화를 봤어요.
[jaemiinneun yeonghwareul bwasseoyo]
Посмотрел интересный фильм.
Исключение — 있다/없다: Хотя 있다 и 없다 — описательные глаголы, они используют -는, как глаголы действия: 재미있는 (интересный), 맛없는 (невкусный).

Прошедшее время: -(으)ㄴ (действие)

Для глаголов действия в прошедшем времени используется -(으)ㄴ — то же самое окончание, что и для описательных глаголов в настоящем!

-(으)ㄴ (прошедшее)
основа глагола действия + (으)ㄴ
Показывает завершённое действие: "сделавший", "сделанный"
먹다 → 먹은 음식
есть → съеденная еда
가다 → 간 사람
идти → ушедший человек
읽다 → 읽은 책
читать → прочитанная книга
만들다 → 만든 음식
делать → приготовленная еда (ㄹ выпадает!)
Примеры в предложениях
어제 먹은 음식이 맛있었어요.
[eoje meogeun eumsigi masisseosseoyo]
Еда, которую вчера ел, была вкусной.
제가 만든 케이크예요.
[jega mandeun keikeuveyo]
Это торт, который я сделал.

Главная путаница: -(으)ㄴ

Окончание -(으)ㄴ используется в двух разных случаях, и это основной источник ошибок:

-(으)ㄴ: два значения
Тип глагола
Значение -(으)ㄴ
Пример
Описательный (형용사)
Настоящее время
작은 집 = маленький дом (сейчас)
Действие (동사)
Прошедшее время
간 사람 = ушедший человек (уже ушёл)
Как различить? Смотрите на тип глагола! 작다 (маленький) — описательный, поэтому 작은 = настоящее. 가다 (идти) — действие, поэтому 간 = прошедшее. Контекст всегда поможет.

Будущее время: -(으)ㄹ

Окончание -(으)ㄹ используется для всех типов глаголов и обозначает будущее действие или намерение.

-ㄹ
основа на гласную + ㄹ
가다 → 갈 곳
идти → место, куда пойду
하다 → 할 일
делать → дело, которое нужно сделать
-을
основа на согласную + 을
먹다 → 먹을 음식
есть → еда, которую буду есть
읽다 → 읽을 책
читать → книга, которую прочитаю
Примеры в предложениях
내일 할 일이 많아요.
[naeil hal iri manayo]
Завтра много дел, которые нужно сделать.
갈 곳이 없어요.
[gal gosi eopseoyo]
Некуда идти.
마실 물 좀 주세요.
[masil mul jom juseyo]
Дайте, пожалуйста, воды для питья.

Использование с 것 (номинализация)

Атрибутивные формы часто используются с 것 [geot] (вещь, дело), превращая глагол в существительное. В разговорной речи 것 сокращается до 거 [geo].

Глагол + 것/거 = существительное
먹는 것을 좋아해요.
[meongneun geoseul joahaeyo]
Люблю есть (= то, что ем / еду).
어제 산 거예요.
[eoje san geoyeyo]
Это то, что купил вчера.
내일 할 거예요.
[naeil hal geoyeyo]
Сделаю завтра (= это то, что сделаю завтра).
먹다 + 것 во всех временах

Значение

Диалог: В книжном магазине

지민:
요즘 읽는 책 있어요?
[yojeum ingneun chaek isseoyo] — Сейчас читаешь какую-нибудь книгу?
읽는 = 읽다 + 는 (настоящее, действие)
수호:
네, 지난주에 산 소설을 읽고 있어요.
[ne, jinanjue san soseoreul ilgo isseoyo] — Да, читаю роман, который купил на прошлой неделе.
산 = 사다 + ㄴ (прошедшее, действие)
지민:
재미있는 책이에요?
[jaemiinneun chaegieyo] — Интересная книга?
재미있는 = 재미있다 + 는 (исключение: 있다 использует -는)
수호:
네, 정말 재미있어요. 다 읽은 후에 빌려줄게요.
[ne, jeongmal jaemiisseoyo. da ilgeun hue billyeojulgeyo] — Да, очень интересная. Когда дочитаю, одолжу вам.
읽은 후에 = после того как прочитаю (прошедшее атрибутивное + 후에)
지민:
고마워요! 저도 읽을 책을 찾고 있었어요.
[gomawoyo! jeodo ilgeul chaegeul chatgo isseosseoyo] — Спасибо! Я тоже искал книгу для чтения.
읽을 = 읽다 + 을 (будущее)

Заключение

Атрибутивные формы — одна из самых важных грамматических конструкций корейского языка. Они позволяют строить сложные предложения и описывать существительные с помощью глаголов.

Краткий обзор

-는
Настоящее (действие)
먹는, 가는, 하는
-(으)ㄴ
Настоящее (описание) / Прошедшее (действие)
큰, 작은 / 먹은, 간
-(으)ㄹ
Будущее (все глаголы)
먹을, 갈, 할

Запомни

-는 (настоящее, действие): 먹는 사람 (человек, который ест), 가는 길 (дорога, по которой идёшь). Основа на ㄹ — ㄹ выпадает: 살다 → 사는.
-(으)ㄴ (настоящее, описание): 큰 집 (большой дом), 작은 가방 (маленькая сумка). Исключения: 있다/없다 используют -는.
-(으)ㄴ (прошедшее, действие): 먹은 음식 (съеденная еда), 간 사람 (ушедший человек). Та же форма, что для описательных в настоящем!
-(으)ㄹ (будущее, все): 먹을 것 (то, что буду есть), 갈 곳 (место, куда пойду), 할 일 (дело, которое нужно сделать).
С 것/거: Атрибутивная форма + 것 превращает глагол в существительное: 먹는 것 (еда/то, что ем), 산 것 (купленное), 할 것 (то, что сделаю).
