Расширенные значения 로: маршрут, материал, известность

(으)로 — 경유·재료·유명
시청으로 해서 가세요 (езжайте через мэрию), 콩으로 만들어요 (делают из сои), 김치로 유명해요 (известен кимчхи) — три конструкции с частицей 로.

1. N(으)로 해서 — «через, по маршруту»

Промежуточный пункт пути. Отвечает на вопрос «каким путём?».

N(으)로 해서 + глагол движения
[N(eu)ro haeseo]
через N / по маршруту N
시청으로 해서 가는 게 빨라요.
[sicheongeuro haeseo ganeun ge ppallayo.]
Быстрее ехать через мэрию.
공원으로 해서 걸어갔어요.
[gongwoneuro haeseo georeogasseoyo.]
Пошёл пешком через парк.
부산에서 도쿄로 해서 뉴욕까지 갔어요.
[busaneseo dokyoro haeseo nyuyokkkaji gasseoyo.]
Из Пусана через Токио добрался до Нью-Йорка.
이 길로 해서 가면 십 분 걸려요.
[i gillo haeseo gamyeon sip bun geollyeoyo.]
Если ехать этой дорогой, займёт десять минут.
ЧастицаЗначениеПример
N(으)로направление학교로 가요 (иду в школу)
N(으)로 해서через промежуточный пункт시청으로 해서 가요
N을/를 지나서миновав N공원을 지나서 가요
N에서откуда집에서 나왔어요
Как спросить дорогу: «어디로 해서 가면 돼요?» — «каким путём лучше ехать?». Ответ обычно тоже с 로 해서.

2. N(으)로 만들다 — «сделать из»

Материал, из которого что-то изготовлено. Важно отличать от 로 (инструмент) и 이/가 되다 (превращение).

N(으)로 만들다 / N(으)로 만든 N
[N(eu)ro mandeulda / N(eu)ro mandeun N]
сделать из N / сделанный из N
된장은 콩으로 만들어요.
[doenjangeun kongeuro mandeureoyo.]
Твенджан делают из соевых бобов.
이 가방은 가죽으로 만든 거예요.
[i gabangeun gajugeuro mandeun geoyeyo.]
Эта сумка сделана из кожи.
한지는 나무껍질로 만듭니다.
[hanjineun namukkeopjillo mandeumnida.]
Ханджи изготавливают из древесной коры.
막걸리는 쌀로 만든 술이에요.
[makgeollineun ssallo mandeun surieyo.]
Макколли — напиток из риса.
КонструкцияЗначениеПример
N(으)로 만들다материал콩으로 만들어요 (из сои)
N(으)로 (도구)инструмент젓가락으로 먹어요 (палочками)
N이/가 되다становиться N의사가 됐어요 (стал врачом)
N(으)로 바뀌다смениться на N회의가 다음 주로 바뀌었어요

3. N(으)로 유명하다 — «известен чем-либо»

Чем славится место, человек или продукт. Одна из самых нужных фраз при рассказе о родном крае.

N(으)로 유명하다 / N(으)로 유명한 N
[N(eu)ro yumyeonghada / N(eu)ro yumyeonghan N]
известен, славится N
전주는 비빔밥으로 유명해요.
[jeonjuneun bibimbabeuro yumyeonghaeyo.]
Чонджу славится пибимпапом.
제주도는 아름다운 바다로 유명합니다.
[jejudoneun areumdaun badaro yumyeonghamnida.]
Чечжудо известен красивым морем.
이 가게는 냉면으로 유명한 집이에요.
[i gageneun naengmyeoneuro yumyeonghan jibieyo.]
Это заведение славится нэнмёном.
그분은 친절하기로 유명해요.
[geubuneun chinjeolhagiro yumyeonghaeyo.]
Он известен своей доброжелательностью.
С глаголом — 기로 유명하다: 친절하기로 유명하다 (славится добротой), 맵기로 유명하다 (славится остротой). После существительного — 로 유명하다.

Частые ошибки

✗ 전주는 비빔밥을 유명해요  →  ✓ 전주는 비빔밥으로 유명해요 (нужна частица 로)

✗ 콩을 만든 된장  →  ✓ 콩으로 만든 된장 (материал — только с 로)

✗ 친절한 것으로 유명해요  →  ✓ 친절하기로 유명해요 (с прилагательным — форма 기로)

4. Мини-диалог: рассказ о родном городе (고향 소개)

Кореец расспрашивает иностранца о его городе.

민호:
고향은 무엇으로 유명해요?
Чем известен ваш родной город?
안나:
오래된 성당으로 유명해요. 돌로 만든 건물이에요.
Известен старым собором. Здание построено из камня.
민호:
한국 사람들도 많이 가나요?
Корейцы туда тоже часто ездят?
안나:
네. 보통 바르샤바로 해서 가요.
Да. Обычно едут через Варшаву.
민호:
음식은요? 뭐가 유명해요?
А еда? Что известно?
안나:
감자로 만든 요리가 유명해요. 한국 감자전이랑 비슷해요.
Известны блюда из картофеля. Похоже на корейские камджаджоны.
