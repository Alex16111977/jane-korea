Номинализация 기/는 것

명사화: 동사를 명사로 바꾸기 [myeongsahwa: dongsareul myeongsaro bakkugi]
Как превратить глагол в существительное и строить сложные предложения

Что такое номинализация?

Номинализация - это превращение глагола или прилагательного в существительное. В русском мы делаем это постоянно: читать -> чтение, бегать -> бег, петь -> пение.

В корейском языке для этого есть два основных способа: суффикс -기 и конструкция -는 것. Оба превращают глагол в "то, что делается", но используются в разных ситуациях.

-기 [gi]
основа глагола + 기
Создает абстрактное существительное. Часто используется в устойчивых выражениях, с прилагательными и в названиях.
읽다 -> 읽기 [ilgi]
читать -> чтение
듣다 -> 듣기 [deutgi]
слушать -> аудирование
쓰다 -> 쓰기 [sseugi]
писать -> письмо (навык)
말하다 -> 말하기 [malhagi]
говорить -> говорение
-는 것 [neun geot]
основа глагола + 는 것
Более универсальная конструкция. Означает "то, что (кто-то делает)". Может сокращаться до -는 거 в разговорной речи.
먹다 -> 먹는 것 [meongneun geot]
есть -> то, что ешь / еда (процесс)
보다 -> 보는 것 [boneun geot]
смотреть -> то, что смотришь
공부하다 -> 공부하는 것 [gongbuhaneun geot]
учиться -> то, что учишь / учеба
노래하다 -> 노래하는 것 [noraehaneun geot]
петь -> то, что поешь / пение

Когда использовать -기

Суффикс -기 часто встречается в устойчивых конструкциях с определенными словами. Запомните эти важные паттерны:

Устойчивые выражения с -기
한국어를 배우기 시작했어요.
Я начал(а) изучать корейский язык.
배우기
изучение (учить + 기)
시작했어요
начал(а)
이 책은 읽기 쉬워요.
Эту книгу легко читать.
읽기
чтение (читать + 기)
쉬워요
легко
약속을 지키기 어려워요.
Трудно сдержать обещание.
지키기
сдерживание (хранить + 기)
어려워요
трудно
Запомните! -기 часто используется перед:
  • 쉽다 [swipda] - легко: 하기 쉽다 (легко делать)
  • 어렵다 [eoryeopda] - трудно: 하기 어렵다 (трудно делать)
  • 시작하다 [sijakhada] - начинать: 하기 시작하다 (начинать делать)
  • 싫다 [silta] - не нравится: 하기 싫다 (не хочется делать)
  • 좋다 [jota] - хорошо: 하기 좋다 (хорошо для дел)
  • 전에 [jeone] - до: 하기 전에 (до того как делать)

Когда использовать -는 것

Конструкция -는 것 [neun geot] более универсальная и используется как подлежащее или дополнение в предложении. В разговорной речи 것 сокращается до 거 [geo].

Примеры с -는 것 / -는 거
음악을 듣는 것을 좋아해요.
Я люблю слушать музыку.
듣는 것을
слушание (+ частица 을)
좋아해요
люблю / нравится
요리하는 것이 취미예요.
Готовка - это мое хобби.
요리하는 것이
готовка (+ частица 이)
취미예요
хобби
운동하는 거 좋아해요? (разговорная форма)
Ты любишь заниматься спортом?
운동하는 거
занятия спортом (разг.)
좋아해요?
нравится?
Временные формы -는 것:
  • Настоящее: 먹는 것 [meongneun geot] - то, что ешь (сейчас)
  • Прошедшее: 먹은 것 [meogeun geot] - то, что ел (раньше)
  • Будущее: 먹을 것 [meogeul geot] - то, что будешь есть

Важное различие

Иногда оба варианта возможны, но смысл немного отличается:

-기 (абстрактно)

한국어 읽기 어려워요.
Корейский трудно читать (в целом).

-는 것 (конкретно)

이 글을 읽는 것이 어려워요.
Читать этот текст трудно (конкретный текст).

Диалог: Хобби и увлечения

수진 [Sudjin]:
취미가 뭐예요?
Какое у вас хобби?
민호 [Minho]:
저는 요리하는 것을 좋아해요. 새로운 음식 만들기가 재미있어요.
Я люблю готовить. Делать новую еду - интересно.
요리하는 것 (는 것 - конкретное "готовить"), 만들기 (기 + прилагательное 재미있다)
수진:
저도 먹는 거 좋아해요! 그런데 요리하기 어려워요.
Я тоже люблю есть! Но готовить трудно.
먹는 거 (разг. форма 것 -> 거), 요리하기 어렵다 (기 + "трудно")
민호:
처음에는 어렵지만, 하기 시작하면 쉬워져요.
Сначала трудно, но если начать, становится легко.
하기 시작하다 (기 + "начинать") - устойчивое выражение

Краткий обзор

-기
Абстрактное значение
읽기, 쓰기, 말하기
+ 쉽다, 어렵다, 시작하다
-는 것
Конкретное значение

Разг.: 것 -> 거
Время
-는 것 (наст.)
-은/ㄴ 것 (прош.)
-을/ㄹ 것 (буд.)
