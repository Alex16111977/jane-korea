Оценка действия: -기가 쉽다 · -기에 좋다 · -기 시작하다

-기 + 평가 — «делать легко», «удобно для», «начал делать»
한국어는 배우기가 어려워요 (корейский трудно учить), 살기에 좋은 도시 (город, удобный для жизни) — как оценивать само действие.

1. V-기가 쉽다 / 어렵다 / 힘들다 — «делать легко/трудно»

Превращаем глагол в существительное через -기 и оцениваем само действие. В речи 가 часто опускают.

глагол + -기가 + 쉽다 / 어렵다 / 힘들다 / 편하다
[-giga swipda / eoryeopda / himdeulda / pyeonhada]
делать легко / трудно / тяжело / удобно
ВыражениеЗначениеЗвук
배우기가 어려워요учить трудно
외우기가 쉬워요запоминать легко
찾기가 힘들어요найти тяжело
쓰기가 편해요писать удобно
먹기가 불편해요есть неудобно
한국어 발음은 배우기가 어려워요.
[hangugeo bareumeun baeugiga eoryeowoyo.]
Корейское произношение трудно осваивать.
이 앱은 사용하기가 정말 쉬워요.
[i aebeun sayonghagiga jeongmal swiwoyo.]
Этим приложением очень легко пользоваться.
서울에서는 주차하기가 힘들어요.
[seoureseoneun juchahagiga himdeureoyo.]
В Сеуле тяжело припарковаться.
이 의자는 오래 앉아 있기가 불편해요.
[i uijaneun orae anja itgiga bulpyeonhaeyo.]
На этом стуле неудобно долго сидеть.
Разговорное сокращение: 배우기가 어려워요 → 배우기 어려워요. Смысл тот же, 가 просто выпадает.

2. V-기에 좋다 / 편하다 — «удобно для того, чтобы»

Оценка предмета или места с точки зрения назначения. Часто в определении перед существительным.

глагол + -기에 + 좋다 / 편하다 / 알맞다
[-gie jota / pyeonhada / almatda]
хорош для того, чтобы… / удобен для…
여기는 살기에 좋은 동네예요.
[yeogineun salgie joeun dongneyeyo.]
Это район, в котором хорошо жить.
이 신발은 걷기에 편해요.
[i sinbareun geotgie pyeonhaeyo.]
В этих туфлях удобно ходить.
오늘 날씨는 산책하기에 딱 좋아요.
[oneul nalssineun sanchaekagie ttak joayo.]
Сегодняшняя погода как раз для прогулки.
이 책은 초보자가 읽기에 알맞아요.
[i chaegeun chobojaga ikgie almajayo.]
Эта книга подходит для чтения начинающим.
-기가 쉽다/어렵다-기에 좋다/편하다
О чёмо сложности действияо пригодности предмета или места
Кто оцениваетисполнительнаблюдатель
Пример걷기가 힘들어요 (ходить тяжело)걷기에 좋아요 (хорошо для ходьбы)
В разговоре -기에 часто сокращают до -기: «살기 좋은 동네», «걷기 편한 신발». Так пишут и в рекламе.

3. V-기 시작하다 — «начать делать»

Момент начала действия. Обратите внимание: 시작하다 присоединяется именно к -기, а не к -는 것.

глагол + -기 시작하다
[-gi sijakada]
начать делать…
작년부터 한국어를 배우기 시작했어요.
[jangnyeonbuteo hangugeoreul baeugi sijakaesseoyo.]
С прошлого года начал учить корейский.
갑자기 비가 오기 시작했어요.
[gapjagi biga ogi sijakaesseoyo.]
Внезапно начался дождь.
아이가 걷기 시작했어요.
[aiga geotgi sijakaesseoyo.]
Ребёнок начал ходить.
세 시부터 사람들이 모이기 시작할 거예요.
[se sibuteo saramdeuri moigi sijakal geoyeyo.]
С трёх часов люди начнут собираться.

Частые ошибки

✗ 배우는 것 시작했어요  →  ✓ 배우기 시작했어요 (с 시작하다 идёт только -기)

✗ 한국어를 배우기가 시작했어요  →  ✓ 한국어를 배우기 시작했어요 (здесь 가 не ставится)

✗ 살기에 좋아하는 동네  →  ✓ 살기에 좋은 동네 (좋다 — прилагательное, определение на -(으)ㄴ)

4. Мини-диалог: выбираем квартиру (집 구하기)

Разговор с риелтором.

손님:
이 근처는 살기에 어때요?
Как этот район — для жизни?
중개인:
조용하고 살기 좋은 동네예요.
Тихий, хороший для жизни район.
손님:
지하철역은 찾기가 쉬운가요?
А станцию метро легко найти?
중개인:
걸어서 오 분이라 다니기 편하실 거예요.
Пять минут пешком, ездить будет удобно.
손님:
요즘 집값이 오르기 시작했다고 들었어요.
Слышал, цены на жильё начали расти.
중개인:
맞아요. 그래서 결정하기가 어려우실 텐데 천천히 보세요.
Верно. Решать наверняка будет непросто — смотрите не спеша.
