Урок: Введение в неправильные глаголы

불규칙 동사 입문 [bulgyuchik dongsa ipmun]
ㅂ, ㄷ, ㅅ неправильные — самые частые исключения в корейском языке

Что такое неправильные глаголы?

В корейском языке большинство глаголов спрягаются по стандартным правилам. Но есть группа глаголов, у которых при присоединении окончаний, начинающихся на гласную, основа меняется. Это и есть 불규칙 동사 [bulgyuchik dongsa] — неправильные глаголы.

Почему это важно? Неправильные глаголы встречаются в повседневной речи постоянно. Слова "жарко", "холодно", "красивый", "слышать", "ходить пешком" — все они неправильные! Без знания этих исключений невозможно говорить грамотно.

Ключевой момент: изменение основы происходит только перед гласными окончаниями (-아/어, -으면, -(으)ㄴ и т.д.). Перед согласными (например, -고, -지만, -습니다) глагол спрягается как обычно.

Общий принцип
덥다
жарко (словарная форма)
+ 고
согласное окончание
= 덥고
без изменений
덥다
жарко (словарная форма)
+ 아요
гласное окончание
= 더워요
ㅂ → 워!

В этом уроке мы разберём три самых частых типа неправильных глаголов: ㅂ-неправильные, ㄷ-неправильные и ㅅ-неправильные.

ㅂ-неправильные глаголы (ㅂ 불규칙)

Это самая большая группа неправильных глаголов. При присоединении гласного окончания конечный ㅂ основы заменяется на 우, а затем добавляется окончание.

Правило: ㅂ → 우 + окончание

덥 + 어요 → 더 + 우 + 어요 → 더워요

ㅂ убирается, добавляется 우, затем 우+어 сливаются в 워

Почему 와, а не 워? Потому что гласная основы — ㅗ, а по правилу гармонии гласных ㅗ сочетается с 아: 우+아 = 와.
Внимание! Правильные глаголы на ㅂ: Не все глаголы на ㅂ — неправильные! Следующие глаголы спрягаются по обычным правилам:

잡다 [japda] (ловить) → 잡아요 (НЕ *자워요)
좁다 [jopda] (узкий) → 좁아요 (НЕ *조워요)
입다 [ipda] (надевать) → 입어요 (НЕ *이워요)
씹다 [ssipda] (жевать) → 씹어요 (НЕ *씨워요)

ㄷ-неправильные глаголы (ㄷ 불규칙)

При присоединении гласного окончания конечный ㄷ основы заменяется на ㄹ. Это логично: ㄹ — более "мягкий" согласный, он легче сочетается с гласными.

Правило: ㄷ → ㄹ перед гласной

듣 + 어요 → 들 + 어요 → 들어요

ㄷ заменяется на ㄹ, затем добавляется гласное окончание

ㄷ-неправильные
듣다 → 들어요
слышать, слушать [deutda → deureoyo]
걷다 → 걸어요
ходить пешком [geotda → georeoyo]
묻다 → 물어요
спрашивать [mutda → mureoyo]
싣다 → 실어요
грузить [sitda → sireoyo]
Правильные глаголы на ㄷ
Спрягаются обычно — ㄷ остаётся!
닫다 → 닫아요
закрывать [datda → dadayo]
받다 → 받아요
получать [batda → badayo]
믿다 → 믿어요
верить [mitda → mideoyo]
Осторожно с 묻다! В корейском два глагола 묻다:
- 묻다 (спрашивать) — неправильный: 물어요 [mureoyo]
- 묻다 (закапывать, хоронить) — правильный: 묻어요 [mudeoyo]
Различить их можно только по контексту!

ㅅ-неправильные глаголы (ㅅ 불규칙)

При присоединении гласного окончания конечный ㅅ просто исчезает. Он не заменяется другим звуком — он удаляется, и предыдущая гласная напрямую соединяется с окончанием.

Правило: ㅅ исчезает перед гласной

짓 + 어요 → 지 + 어요 → 지어요

ㅅ убирается, гласные основы и окончания идут подряд

ㅅ-неправильные
짓다 → 지어요
строить, составлять [jitda → jieoyo]
낫다 → 나아요
выздоравливать, быть лучше [natda → naayo]
긋다 → 그어요
проводить линию [geutda → geueoyo]
잇다 → 이어요
соединять [itda → ieoyo]
Правильные глаголы на ㅅ
Спрягаются обычно — ㅅ остаётся!
웃다 → 웃어요
смеяться [utda → useoyo]
씻다 → 씻어요
мыть [ssitda → ssiseoyo]
벗다 → 벗어요
снимать (одежду) [beotda → beoseoyo]

Запомните: Перед согласными окончаниями (-고, -지만, -습니다, -지 않다) неправильные глаголы ведут себя как обычные! Изменения происходят только перед гласными.

Диалог: Разговор о погоде

수진 (Суджин):
오늘 정말 더워요.
Сегодня очень жарко.
덥다 → 더워요 (ㅂ-неправильный)
민호 (Минхо):
네, 어제는 추웠는데 오늘은 더워요.
Да, вчера было холодно, а сегодня жарко.
춥다 → 추웠는데 (ㅂ-неправильный, прошедшее время)
수진:
한국어 공부가 어려워요?
Изучение корейского сложное?
어렵다 → 어려워요 (ㅂ-неправильный)
민호:
발음은 어려워요. 하지만 문법은 쉬워요.
Произношение сложное. Но грамматика легкая.
쉽다 → 쉬워요 (ㅂ-неправильный)
수진:
음악을 들어요? 한국 음악이 아름다워요!
Слушаете музыку? Корейская музыка прекрасна!
듣다 → 들어요 (ㄷ-неправильный), 아름답다 → 아름다워요 (ㅂ-неправильный)
민호:
네, 매일 걸어요. 걸으면서 음악을 들어요.
Да, каждый день хожу пешком. Слушаю музыку во время прогулки.
걷다 → 걸어요, 걸으면서 (ㄷ-неправильный)

Запомните!

ㅂ 불규칙: ㅂ → 우 перед гласными. Обычно получается 워 (더워요, 추워요). Исключения: 돕다 → 도와요, 곱다 → 고와요 (потому что 와, не 워). Правильные: 잡다, 좁다, 입다.
ㄷ 불규칙: ㄷ → ㄹ перед гласными. 듣다 → 들어요, 걷다 → 걸어요, 묻다 (спрашивать) → 물어요. Правильные: 닫다, 받다, 믿다.
ㅅ 불규칙: ㅅ просто исчезает перед гласными. 짓다 → 지어요, 낫다 → 나아요. Правильные: 웃다, 씻다, 벗다.
Ключевое правило: Изменения происходят ТОЛЬКО перед гласными окончаниями (-아/어, -으면, -(으)ㄴ). Перед согласными (-고, -지만, -습니다) глаголы спрягаются обычно!
Как запомнить? К сожалению, нужно просто выучить, какие глаголы правильные, а какие нет. Хорошая новость: неправильных глаголов не так много, и они очень частотные — вы быстро их запомните на практике.
