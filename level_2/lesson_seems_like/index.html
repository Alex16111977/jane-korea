Урок 2: -는 것 같다 / -(으)ㄹ 것 같다

추측 표현 [chucheuk pyohyeon] — выражение предположений
Как сказать "кажется", "наверное", "похоже" — одна из самых частых конструкций в корейском!

1. Зачем нужна конструкция 것 같다?

Корейцы очень часто используют 것 같다. Эта конструкция позволяет:

  • Выразить предположение: "Кажется, идёт дождь"
  • Смягчить высказывание: вместо "это вкусно" — "кажется, это вкусно" (вежливее)
  • Выразить неуверенность: "Наверное, он придёт"

Конструкция меняется в зависимости от времени: настоящее, прошедшее, будущее.

3. Настоящее время: подробно

Правило: Для глаголов в настоящем времени используем -는 것 같다. Для прилагательных — -(으)ㄴ 것 같다 (как и определительная форма прилагательных).
저 사람이 한국 사람인 것 같아요.
[jeo sarami hanguk saramin geot gatayo]
Кажется, тот человек — кореец.
이다 → -인 것 같다
지금 자는 것 같아요.
[jigeum janeun geot gatayo]
Кажется, сейчас спит.
자다 → 자는 (глагол + -는)
이 가방이 비싼 것 같아요.
[i gabangi bissan geot gatayo]
Кажется, эта сумка дорогая.
비싸다 → 비싼 (прилагательное + -(으)ㄴ)
밖에 눈이 오는 것 같아요.
[bakke nuni oneun geot gatayo]
Кажется, на улице идёт снег.

4. Прошедшее время: подробно

Для глаголов в прошедшем времени используем -(으)ㄴ 것 같다 (внимание: та же форма, что у прилагательных в настоящем, но с глаголами означает прошлое!).

어제 비가 온 것 같아요.
[eoje biga on geot gatayo]
Кажется, вчера шёл дождь.
민수가 벌써 먹은 것 같아요.
[minsuga beolsseo meogeun geot gatayo]
Кажется, Минсу уже поел.
그 사람이 집에 간 것 같아요.
[geu sarami jibe gan geot gatayo]
Кажется, тот человек пошёл домой.

5. Будущее время: подробно

Для предположений о будущем используем -(으)ㄹ 것 같다.

오늘 바쁠 것 같아요.
[oneul bappeul geot gatayo]
Наверное, сегодня буду занят.
바쁘다 → 바쁠 (ㅡ убирается)
이 영화가 재미있을 것 같아요.
[i yeonghwaga jaemiisseul geot gatayo]
Наверное, этот фильм будет интересным.
시간이 오래 걸릴 것 같아요.
[sigani orae geollil geot gatayo]
Наверное, займёт много времени.
내일 못 갈 것 같아요.
[naeil mot gal geot gatayo]
Наверное, завтра не смогу пойти.

Вежливость: Корейцы используют 것 같다 для смягчения своего мнения. Вместо прямого 맛있어요 (вкусно) часто говорят 맛있는 것 같아요 (кажется, вкусно). Это звучит скромнее и вежливее!

7. Диалог: Планы на выходные

지영 [Jiyeong]:

Что будете делать на выходных?
수진 [Sudjin]:
날씨가 좋을 것 같아서 등산을 가려고요.
Наверное, погода будет хорошая, так что собираюсь в горы.
좋을 것 같다 — будущее предположение
지영:
그런데 일기 예보에서 비가 올 것 같다고 했어요.
Но в прогнозе погоды сказали, что, наверное, будет дождь.
올 것 같다 + 고 하다 — косвенная речь с предположением
수진:
정말요? 그러면 영화를 보는 게 좋을 것 같아요.
Правда? Тогда, наверное, лучше посмотреть фильм.
지영:
새로 나온 한국 영화가 재미있는 것 같아요. 같이 볼까요?
Кажется, новый корейский фильм интересный. Посмотрим вместе?
수진:
좋아요! 그 영화 벌써 본 사람들이 좋다고 한 것 같아요.
Хорошо! Кажется, те, кто уже посмотрел, сказали, что хороший.

📋 Запомни!

Настоящее (глагол): -는 것 같다 — 비가 오는 것 같아요 (кажется, дождь идёт)
Настоящее (прилаг.): -(으)ㄴ 것 같다 — 비싼 것 같아요 (кажется, дорого)
Прошедшее (глагол): -(으)ㄴ 것 같다 — 간 것 같아요 (кажется, ушёл)
Будущее: -(으)ㄹ 것 같다 — 올 것 같아요 (наверное, придёт)
Смягчение: Корейцы используют 것 같다 для вежливости — вместо прямого утверждения говорят "кажется"
