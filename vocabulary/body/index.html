💡 Части тела в предложениях

🥽 ... болит
머리 가 + 아파요 → 머리가 아파요
Часть тела + 가/이 + 아프다 = "... болит". 가 после гласной, 이 после согласной.
배가 아파요
Живот болит
눈이 아파요
Глаза болят
목이 아파요
Горло болит
다리가 아파요
Нога болит
💦 ... мыть / чистить
손 을 + 씻다 → 손을 씻다
Часть тела + 을/를 + глагол. 을 после согласной, 를 после гласной.
손을 씻어요
Помыл руки
얼굴을 씻어요
Умыл лицо
머리를 감았요
Помыл голову (волосы)
👀 ... большой / маленький
눈 이 + 크다 / 작다
Описание внешности: часть тела + 이/가 + 크다(빠야요) / 작다(작아요) / 길다(길어요)
눈이 클요
Глаза большие
코가 높아요
Нос высокий
다리가 길어요
Ноги длинные
입이 작아요
Рот маленький
