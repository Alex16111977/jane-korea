💡 Вопросительные слова в корейском

뭐 / 무엇 — что?
이게 + 뭐예요? → 이게 뭐예요?
«Что это?». 뭐 — разговорное, 무엇 — формальное. Для 1급 достаточно 뭐.
누구 / 누가 — кто?
저 사람이 + 누구 + 예요? → 저 사람이 누구예요?
«Кто тот человек?». Когда 누구 — подлежащее, становится 누가: «누가 왔어요?» — «Кто пришёл?»
어디 — где? куда?
어디 에 + 가요? → 어디에 가요?
«Куда идёшь?». С 있다: «어디에 있어요?» — «Где находится?»
언제 / 왜 / 어떻게
언제 와요?
Когда придёшь?
왜 그래요?
Почему так?
어떻게 해요?
Как это делать?
어느 vs 무슨 vs 어떤 — три «какой»
어느 나라?
어느 = какой из конкретного списка (выбор)
무슨 일이에요?
무슨 = что за? какого рода? (категория)
어떤 사람이에요?
어떤 = какого типа? какой по характеру? (описание)
