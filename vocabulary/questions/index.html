💡 Вопросительные слова в корейском

무엇 / 7 이게 뫼예요?
이게 + 뫼예요? → 이게 뫼예요?
«Что это?». 뭐 — разговорное, 무엇 — формальное. Используем для предметов.
누구 / Кто?
저 사람이 + 누구 + 예요? → 저 사람이 누구예요?
«Кто тот человек?». Когда 누구 — подлежащее, становится 누가: «누가 왔어요?» — «Кто пришёл?»
어디 / Где? Куда?
어디 에 + 가요? → 어디에 가요?
«Куда идёшь?». С глаголом 있다 получается «어디에 있어요?» — «Где находится?»
언제 / 웨 / 어떼게
언제 왔요?
Когда придёшь?
웨 그뎰요?
Почему так?
어떼게 해요?
Как это делать?
