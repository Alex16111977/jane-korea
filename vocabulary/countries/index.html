Изучаем названия стран и национальностей

💡 Как говорить о странах по-корейски

Ⅰ. "Я из ..."
러시아 + 에서 + 왕어요 → 저는 러시아에서 왕어요
에서 왕다 = "приехал из". Буквально: "от России пришёл".
저는 러시아에서 왕어요.
Я из России.
저는 미국에서 왕어요.
Я из США.
저는 일본에서 왕어요.
Я из Японии.
Ⅱ. Национальность
한국 + 사람 + 이에요 → 한국 사람이에요
사람 = человек. Страна + 사람 = национальность.
저는 한국 사람이에요.
Я кореец/кореянка.
저는 러시아 사람이에요.
Я русский/русская.
저는 중국 사람이에요.
Я китаец/китаянка.
Ⅲ. "Еду в страну"
한국 + 에 + 가요 → 한국에 가요
에 — частица направления. 가다 = идти/ехать.
한국에 가요.
Еду в Корею.
일본에 소판가가 싶어요.
Хочу съездить в Японию.
내년 프랑스에 가요.
В следующем году еду во Францию.
Ⅳ. Язык страны
한국 + 어 + 를 + 배워요 → 한국어를 배워요
Страна + 어 = язык. 를/을 — частица объекта.
저는 한국어를 배워요.
Я учу корейский.
영어를 갢함니다.
Говорю по-английски.
일본어를 움는 거이 어려워요.
Писать по-японски сложно.
한국
