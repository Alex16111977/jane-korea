Откуда берутся дни недели (ханджа)
Каждый день недели = элемент природы + 요일. Запомнив элементы, вы запомните все 7 дней логично.

Эта система пришла из китайской философии пяти элементов + солнце и луна.
В [день недели] + действие
월요일 에 + 학교에 가요 → 월요일에 학교에 가요
«В понедельник иду в школу». Частица 에 указывает момент времени.
Сегодня / вчера / завтра (без 에!)
오늘 에 + 바빠요 → 오늘 바빠요
«Сегодня занят». После 오늘/어제/내일 НЕ ставим 에.
어제 영화를 봤어요
Вчера смотрел фильм
내일 만나요
Завтра встречаемся
Утром / днём / вечером / ночью
아침 에 + 일어나요 → 아침에 일어나요
«Утром встаю». После 아침/점심/저녁/밤 ставим 에.
Какой сегодня день?
오늘이 무슨 요일이에요? → 오늘은 월요일이에요
«Какой сегодня день? — Сегодня понедельник.» 무슨 요일 = «какой день недели».
Пример полного расписания
Соединяем дни недели, время суток и действия в связный рассказ:
월요일 아침에 학교에 가요.
В понедельник утром иду в школу.
화요일 저녁에 친구를 만나요.
Во вторник вечером встречаюсь с другом.
수요일 오후에 운동해요.
В среду после обеда занимаюсь спортом.
주말에 영화를 봐요.
В выходные смотрю фильм.
