Названия животных и как говорить о них на корейском

💡 Как говорить о животных

1. Счётное слово 마리
고양이 + 한 마리 → одна кошка
개 + 두 마리 → две собаки
마리 — счётное слово для ВСЕХ животных. Используется с родными корейскими числами (하나, 둘, 셋...).
2. 키우다 — "держать питомца"
고양이 + 를 + 키워요 → Держу кошку
키우다 (키워요) — "растить, держать (животное, ребёнка, растение)". Используется с винительным падежом 을/를.
3. 좋아하다 — "любить"
저는 + 강아지를 + 좋아해요 → Люблю щенят
좋아하다 (좋아해요) — "любить, нравиться". Объект любви идёт с 을/를.
4. 개 vs 강아지
개 = собака (вообще)
강아지 = щенок / ласково "пёсик"
개 — нейтральное "собака". 강아지 — буквально "щенок", но часто используется ласково для любой собаки, как "пёсик".
