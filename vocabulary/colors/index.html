Названия цветов и как использовать их в речи

💡 Как использовать цвета в корейском

Цвет = существительное
빨간색 = красный цвет
색 [сэк] = цвет. Полная форма используется когда говорим о цвете как таковом.
Цвет + существительное (убираем 색)
빨간색 + 사과 → 빨간 사과
빨간 사과 = красное яблоко. Убираем 색 и ставим цвет перед существительным.
파란색 + 하늘 → 파란 하늘
파란 하늘 = синее небо
🔄 Альтернативные формы
Чёрный
검은색 = 검정색 = 까만색
까만 (까맛다) — разговорный, 검은 (검다) — нейтральный
Белый
희색 = 하얀색 = 백색
희 (희다) — сокращённая форма, 하얀 (하얇다) — полная

🗣 «Оно красное» — настоящее время

Самая частая форма в речи. ㅎ-неправильные: при добавлении -어요 ㅎ исчезает, а ㅏ→ㅐ.

빨것다
빨개요
ppalgaeyo
(оно) красное
파랏다
파래요
paraeyo
(оно) синее
노랏다
노래요
noraeyo
(оно) жёлтое
까맛다
까매요
kkamaeyo
(оно) чёрное
하얇다
하얌요
hayaeyo
(оно) белое
이 꼬이 빨개요. → Этот цветок красный.
[i kkochi ppalgaeyo] — пример с реальным подлежащим и глаголом-прилагательным
감색 / 회색 — без изменений
Это 한자 слова (не ㅎ-неправильные). Ставятся напрямую перед существительным: 감색 가방 (коричневая сумка), 회색 왱 (серая одежда). В настоящем времени — 감색이에요 / 회색이에요.
❓ Как спросить «какого цвета?»
무습 색이에요?
[мусын сэгиеё] museun saegieyo?
Какого это цвета?
무습 색을 좋아해요?
[мусын сэгыль чоаэё] museun saegeul joahaeyo?
Какой цвет вам нравится?
무습 색 왱을 좋아해요?
[мусын сэк осыль чоаэё] museun saek oseul joahaeyo?
Одежду какого цвета вы любите?
색껸이 어떔요?
[сэккари оттэё] saekkkari eottaeyo?
Как вам цвет? (что думаете о цвете?)
🎨 Смешение цветов
+ = 빨간색 + 파란색 = 보라색
+ = 빨간색 + 노란색 = 주황색
+ = 파란색 + 노란색 = 초록색
+ = 희색 + 검은색 = 회색
