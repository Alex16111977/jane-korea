⏰ Наречия времени

시간 부사 [сиган буса]

Когда что происходит: сегодня, вчера, всегда, иногда

💡 Как использовать наречия времени

1. Позиция в предложении
오늘 학교에 가요 = 학교에 오늘 가요
Наречие времени обычно ставится в начале предложения или перед сказуемым. Оба варианта корректны.
2. 오늘 / 어제 / 내일 — БЕЗ частицы 에
오늘에 → 오늘
С "сегодня/вчера/завтра" частица 에 НЕ ставится. Нельзя говорить 오늘에 — только 오늘.
3. 항상 / 가끔 / 자주 — частота
항상 + 커피를 마셔요 → Всегда пью кофе
항상 (всегда), 자주 (часто), 가끔 (иногда) — ставятся перед глаголом и описывают частоту действия.
4. 절대 = только с отрицанием
절대 + 안 + 먹어요 → Никогда не ем
절대 "никогда" используется ТОЛЬКО с отрицанием (안 или 못). Без отрицания фраза будет неправильной.
5. 벌써 vs 이미 — оба "уже"
벌써 12시예요?
벌써 — "уже?!" с удивлением ("так быстро?"). Эмоциональная окраска.
이미 먹었어요
이미 — "уже" нейтрально, констатация факта. Без эмоций.
