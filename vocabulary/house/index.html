💡 Как говорить о доме и предметах в нём

В [комнате] — частица 에
방 + 에 + 있어요 → 방에 있어요
место + 에 + 있다 = "в комнате"
거실에 있어요.
Я в гостиной.
부엌에 있어요.
Я на кухне.
침실에 있어요.
Я в спальне.
На / под / рядом — 위에 / 아래에 / 옆에
책상 + 위에 → 책상 위에
предмет + 위에 (на) / 아래에 (под) / 옆에 (рядом)
소파 위에
на диване
침대 옆에
рядом с кроватью
의자 아래에
под стулом
У меня есть [вещь] — 이/가 있어요
소파 + 가 + 있어요 → 소파가 있어요
вещь + 이/가 + 있다 = "есть диван"
냉장고가 있어요.
Есть холодильник.
텔레비전이 있어요.
Есть телевизор.
Вопрос: где находится?
어디에 있어요?
"Где находится?" — универсальный вопрос о местоположении
— 의자가 어디에 있어요?
— Где стул?
— 테이블 옆에 있어요.
— Рядом со столом.
💡 Важно: два значения слова 방
Слово 방 (bang) означает и «комнату» в общем смысле, и «спальню» в частности — точное значение определяется контекстом. Чтобы недвусмысленно сказать именно «спальня», используйте 침실 (chimsil). Для других комнат есть свои слова: 거실 (гостиная), 부엌 (кухня), 욕실 (ванная), 화장실 (туалет).
