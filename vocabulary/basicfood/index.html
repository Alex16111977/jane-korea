Изучаем базовые продукты и напитки

💡 Как использовать еду в корейской речи

Правило 1: Есть (кушать)
еда + 을/를 + 먹어요 → 밥을 먹어요
«Ем рис». Глагол 먹다 (есть). 을 — после согласной, 를 — после гласной.
김치를 먹어요
Ем кимчи
빵을 먹어요
Ем хлеб
국수를 먹어요
Ем лапшу
Правило 2: Пить
напиток + 을/를 + 마셔요 → 물을 마셔요
«Пью воду». Глагол 마시다 используется только для напитков.
커피를 마셔요
Пью кофе
우유를 마셔요
Пью молоко
차를 마셔요
Пью чай
Правило 3: Любить еду
еда + 을/를 + 좋아해요 → 김치를 좋아해요
«Люблю кимчи». Глагол 좋아하다 — любить (что-то).
사과를 좋아해요
Люблю яблоки
고기를 좋아해요
Люблю мясо
커피를 좋아해요
Люблю кофе
Правило 4: Вкусно / невкусно
еда + 이/가 + 맛있어요 / 맛없어요
이 음식이 맛있어요 — «Эта еда вкусная». 맛있다 — вкусно, 맛없다 — невкусно.
김치가 맛있어요
Кимчи вкусное
빵이 맛있어요
Хлеб вкусный
이 수프가 맛없어요
Этот суп невкусный
