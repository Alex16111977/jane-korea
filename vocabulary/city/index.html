도시와 장소 [тосива чанъсо]

Места в городе на корейском языке!

💡 Как говорить о местах в городе

1. Идти куда — 에 가다
학교 + 에 + 가요 → 학교에 가요
место + 에 + 가다 = «идти куда-то». 에 — частица направления.
공원에 가요.
Иду в парк.
병원에 가요.
Иду в больницу.
은행에 가요.
Иду в банк.
2. Делать что-то где — 에서 + глагол
카페 + 에서 + 커피를 마셔요 → 카페에서 커피를 마셔요
место + 에서 + действие. Важно: 에서 — для действия в месте, 에 — для направления движения.
식당에서 밥을 먹어요.
В ресторане ем.
도서관에서 책을 읽어요.
В библиотеке читаю книгу.
편의점에서 물을 사요.
В круглосуточном покупаю воду.
3. Где находится? — 어디에 있어요?
은행이 어디에 있어요?
«Где банк?» — существительное + 이/가 + 어디에 있어요?
— 약국이 어디에 있어요?
— Где аптека?
— 백화점 옆에 있어요.
— Рядом с универмагом.
4. Близко / далеко — 에서 가까워요 / 멀어요
집 + 에서 + 멀어요 → 집에서 멀어요
X에서 가까워요 (близко от X) / 멀어요 (далеко от X). 에서 здесь = «от».
학교에서 가까워요.
Близко от школы.
공항에서 멀어요.
Далеко от аэропорта.
