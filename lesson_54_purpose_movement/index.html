Урок 9: Цель движения -러/으러

🎯 Что мы изучаем

Сегодня мы изучим грамматическую конструкцию -러/으러, которая используется для:

  • Выражения цели движения ("чтобы сделать что-то")
  • Указания причины перемещения куда-либо
  • Используется ТОЛЬКО с глаголами движения: 가다, 오다, 다니다

💬 Диалог урока

민지: 어디 가요?

Минджи: Куда идёшь?

준호: 점심 먹으러 식당에 가요.

Чжунхо: Иду в ресторан, чтобы пообедать.

📚 Грамматическое объяснение

🔑 Концепция цели движения

Конструкция -러/으러 присоединяется к основе глагола и выражает цель перемещения — "идти/приходить/ходить куда-то, чтобы сделать что-то". На русский переводится как "чтобы". Важное ограничение: эта конструкция используется только с глаголами движения — 가다 (идти), 오다 (приходить), 다니다 (ходить/посещать).

Правила образования

1. Согласная основа + 으러

Если основа глагола оканчивается на согласную букву (кроме ㄹ):

먹다 (есть) → 먹 + 으러 = 먹으러 (чтобы поесть)

읽다 (читать) → 읽 + 으러 = 읽으러 (чтобы почитать)

먹으러 가다 — идти, чтобы поесть

2. Гласная основа + 러

Если основа глагола оканчивается на гласную букву:

사다 (покупать) → 사 + 러 = 사러 (чтобы купить)

배우다 (учить) → 배우 + 러 = 배우러 (чтобы учить)

사러 가다 — идти, чтобы купить

3. Основа на ㄹ + 러

Если основа глагола оканчивается на ㄹ, добавляем просто 러:

놀다 (играть/гулять) → 놀 + 러 = 놀러 (чтобы поиграть/погулять)

빌리다 → 빌리 + 러 = 빌리러 (чтобы одолжить)

놀러 오다 — приходить в гости (приходить, чтобы погулять)

⚠️ Важно!

Конструкция -러/으러 используется только с глаголами движения:

✅ 먹으러 가요 (идти, чтобы поесть)

✅ 배우러 왔어요 (пришёл, чтобы учить)

✅ 운동하러 다녀요 (ходить, чтобы заниматься спортом)

❌ 먹으러 앉아요 — неправильно! (앉다 — не глагол движения)

📝 Примеры использования

친구를 만나러 카페에 가요.

Иду в кафе, чтобы встретиться с другом.

한국어를 배우러 한국에 왔어요.

Приехал в Корею, чтобы учить корейский.

책을 빌리러 도서관에 갔어요.

Ходил в библиотеку, чтобы взять книгу.

놀러 오세요!

Приходите в гости!

📋 Краткое содержание

  • -러/으러 — конструкция цели движения ("чтобы")
  • согласная + 으러: 먹으러 (чтобы поесть)
  • гласная + 러: 사러 (чтобы купить)
  • ㄹ + 러: 놀러 (чтобы погулять)
  • Используется только с 가다, 오다, 다니다
