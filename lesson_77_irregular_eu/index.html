Неправильные глаголы ㅡ-неправильные

🌊 ㅡ-неправильные глаголы

ㅡ исчезает перед гласными!

쓰다 → 써요 (ㅡ выпадает!)

Простое правило: основа заканчивается на ㅡ, которая "убегает" перед гласными

❓ Как работает правило

📏 Обычные глаголы

먹다 → 먹 + 어요 = 먹어요

Основа не меняется

🌊 ㅡ-неправильные

쓰다 → 쓰 + 어요 → 써요

ㅡ в конце основы исчезает перед гласной

💡 ㅡ боится гласных и исчезает!

📝 Пошаговое правило

1

Найдите основу, заканчивающуюся на ㅡ

쓰다 → основа 쓰 (заканчивается на ㅡ)

2

Проверьте окончание

Начинается на гласную (어요, 아요) или согласную (습니다)?

3

Примените правило

Гласная → ㅡ выпадает: 쓰 + 어요 = 써요

Согласная → ㅡ остается: 쓰 + 지만 = 쓰지만

🎯 Когда ㅡ выпадает, а когда нет

Все зависит от первой буквы окончания!

✅ ГЛАСНАЯ = ㅡ ВЫПАДАЕТ

ㅡ ИСЧЕЗАЕТ

-어요, -아요, -었어요

쓰다 → 써요

❌ СОГЛАСНАЯ = ㅡ ОСТАЕТСЯ

ㅡ НЕ МЕНЯЕТСЯ

-습니다, -지만

쓰다 → 쓰지만

✍️ Глаголы и прилагательные

편지를 써요 Пишу письмо 쓰다 → 쓰 + 어요 → 써요 (ㅡ выпадает)
집이 커요 Дом большой 크다 → 크 + 어요 → 커요 (ㅡ выпадает)
너무 바빠요 Очень занят 바쁘다 → 바쁘 + 아요 → 바빠요 (ㅡ выпадает)
정말 예뻐요 Очень красивая 예쁘다 → 예쁘 + 어요 → 예뻐요 (ㅡ выпадает)

⏰ Прошедшее время

어제 편지를 썼어요 Вчера написал письмо 쓰다 → 쓰 + 었어요 → 썼어요
작년보다 더 컸어요 Стал больше, чем в прошлом году 크다 → 크 + 었어요 → 컸어요
어제 너무 바빴어요 Вчера был очень занят 바쁘다 → 바쁘 + 았어요 → 바빴어요

📏 С согласными (ㅡ НЕ выпадает)

편지를 씁니다 Пишу письмо (формально) 쓰다 + 습니다 → 씁니다 (ㅡ не выпадает)
크지만 좋아요 Большой, но хороший 크다 + 지만 → 크지만 (ㅡ не выпадает)
바쁘니까 못 가요 Занят, поэтому не могу пойти 바쁘다 + 니까 → 바쁘니까

💪 Потренируемся!

1. Как сказать "Пишу письмо"?
Подсказка: 쓰다 + 어요
2. "Дом большой" = ?
Подсказка: 크다 + 어요
3. Как сказать "Очень занят"?
Подсказка: 바쁘다 + 아요
4. Переведите: "정말 예뻐요"
5. Почему 쓰다 → 씁니다, а не 써습니다?
6. "Болит голова" = ?
Подсказка: 아프다 + 아요
Ответы:
1. 편지를 써요
2. 집이 커요
3. 너무 바빠요
4. Очень красивая
5. Потому что -습니다 начинается на согласную, ㅡ не выпадает
6. 머리가 아파요

📝 Главное правило!

ㅡ-неправильные: основа заканчивается на ㅡ

Гласное окончание: ㅡ выпадает (쓰다 → 써요)

Согласное окончание: ㅡ остается (쓰다 → 쓰지만)

Главное: Основа должна ЗАКАНЧИВАТЬСЯ на ㅡ!

Это очень частые слова в повседневной речи!
