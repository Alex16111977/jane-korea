Урок 2: Одновременные действия -면서

🔄 Что мы изучаем

Сегодня мы изучим грамматическую конструкцию -면서, которая используется для:

  • Описания двух одновременных действий одного лица
  • Выражения "делая X, делать Y" (while doing)
  • Подлежащее обоих действий должно быть одним и тем же

💬 Диалог урока

민지: 음악을 들으면서 공부해요?

Минджи: Ты учишься, слушая музыку?

준호: 네, 음악을 들으면서 공부하면 더 잘 돼요.

Чжунхо: Да, когда учусь, слушая музыку, получается лучше.

📚 Грамматическое объяснение

🔑 Концепция одновременности

Конструкция -면서 присоединяется к основе глагола и выражает одновременное выполнение двух действий одним субъектом. Переводится как "делая...", "пока...", "в то время как...". Важно: подлежащее обеих частей предложения должно совпадать.

Правила образования

1. Согласная основа + 으면서

Если основа глагола оканчивается на согласную букву:

먹다 (есть) → 먹 + 으면서 = 먹으면서

읽다 (читать) → 읽 + 으면서 = 읽으면서

Ем, одновременно... / Читаю, одновременно...

2. Гласная основа + 면서

Если основа глагола оканчивается на гласную букву:

가다 (идти) → 가 + 면서 = 가면서

보다 (смотреть) → 보 + 면서 = 보면서

Идя, одновременно... / Смотря, одновременно...

3. Основа на ㄹ + 면서

Если основа глагола оканчивается на ㄹ, он сохраняется:

살다 (жить) → 살 + 면서 = 살면서

놀다 (играть) → 놀 + 면서 = 놀면서

Живя, одновременно... / Играя, одновременно...

📝 Примеры использования

텔레비전을 보면서 밥을 먹어요.

Ем, смотря телевизор.

노래를 부르면서 샤워해요.

Пою, принимая душ.

웃으면서 이야기했어요.

Рассказывал, улыбаясь.

커피를 마시면서 신문을 읽어요.

Читаю газету, попивая кофе.

📋 Краткое содержание

  • -면서 - конструкция одновременных действий
  • согласная + 으면서: 먹으면서 (ем, одновременно...)
  • гласная + 면서: 가면서 (идя, одновременно...)
  • основа на ㄹ + 면서: 살면서 (живя, одновременно...)
  • Подлежащее обоих действий должно совпадать
