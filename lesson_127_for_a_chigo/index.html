Для такого-то -치고

📖 Что мы изучаем

Частица -치고 работает в двух разных смыслах. С отрицанием она означает «нет ни одного, кто бы не…», а в оценке — «для такого-то на удивление». Общее у них одно: говорящий сравнивает предмет с целой категорией.

  • -치고 + отрицание — «все без исключения», «не найдётся такого, кто…»
  • -치고(는) в оценке — «для…, вопреки ожиданию»
  • Форма 치고는 с 는 — только второе значение
  • Присоединяется к существительному, без различий по гласной и согласной
  • Глаголы подключаются через -(으)ㄴ/는 것치고

💬 Диалог урока

수미: 오늘 날씨 좋네요.

Суми: Хорошая сегодня погода.

지호: 네, 겨울치고 정말 따뜻해요.

Чихо: Да, для зимы правда тепло.

수미: 이 빵 좀 드셔 보세요. 제가 만들었어요.

Суми: Попробуйте этот хлеб. Я сама пекла.

지호: 처음 만든 것치고는 아주 맛있는데요?

Чихо: Для первого раза очень даже вкусно!

수미: 고마워요. 사실 어제도 실패했어요.

Суми: Спасибо. Честно говоря, вчера ещё не получилось.

지호: 처음부터 잘하는 사람치고 노력 안 한 사람 없어요.

Чихо: Не бывает так, чтобы у кого-то сразу выходило без труда.

📚 Грамматическое объяснение

🔑 Два значения одной частицы

В обоих случаях 치고 берёт целую группу и сопоставляет с ней конкретный случай. Если дальше идёт отрицание, группа охватывается полностью: 한국 사람치고 김치를 안 먹는 사람이 없어요 — «среди корейцев не найдётся того, кто не ест кимчи». Если дальше идёт оценка, наоборот, подчёркивается исключение: 겨울치고 따뜻해요 — «зима, а тепло». Различить легко по сказуемому: 없다 и 안 — первое значение, прилагательное или похвала — второе.

Раздел 1: -치고 + отрицание — все без исключения

Существительное + 치고 … 없다 / 안 …

Такая фраза утверждает через двойное отрицание: «нет никого, кто бы не». Сказуемое обязательно отрицательное — иначе смысл ломается.

한국 사람치고 김치를 안 먹는 사람은 없어요.

среди корейцев нет тех, кто не ест кимчи

부모치고 자식 걱정 안 하는 사람 없어요.

нет родителей, которые не тревожились бы о детях

학생치고 시험을 좋아하는 사람은 없겠죠.

вряд ли найдётся студент, который любит экзамены

Раздел 2: -치고(는) — «для такого-то»

Существительное + 치고(는) + оценка

Здесь говорящий отмечает, что случай выбивается из ожиданий по своей категории. Обычно это похвала, реже — упрёк.

겨울치고 날씨가 따뜻하네요.

для зимы погода тёплая

초보치고는 잘하시네요.

для новичка вы отлично справляетесь

이 가격치고는 품질이 좋아요.

для такой цены качество хорошее

오래된 차치고는 잘 달려요.

для старой машины ездит бодро

Раздел 3: как подключить глагол

Глагол + -(으)ㄴ/는 것치고

Сама частица цепляется только к существительному. Чтобы поставить перед ней глагол, его превращают в существительное с помощью 것.

만들다 → 처음 만든 것치고는 맛있어요.

для первой попытки вкусно

배우다 → 한 달 배운 것치고는 잘해요.

для месяца занятий неплохо

급하게 하다 → 급하게 한 것치고 결과가 좋네요.

для сделанного впопыхах результат хорош

Раздел 4: как не перепутать значения

Смотрите на сказуемое

Отрицание в конце — значение «все без исключения». Оценка в конце — значение «для такого-то». Форма с 는 (치고는) во втором значении встречается чаще, в первом её не используют.

봄치고 추운 날이 없어요.

весной не бывает холодных дней — охват группы

봄치고는 춥네요.

для весны холодновато — оценка

✗ 겨울치고는 안 추운 사람이 없어요

смешивать два значения нельзя

📝 Примеры использования

한국 사람치고 김치를 안 먹는 사람은 없어요.

Среди корейцев не найдётся того, кто не ест кимчи.

겨울치고 날씨가 따뜻하네요.

Для зимы погода тёплая.

초보치고는 운전을 잘하시네요.

Для новичка вы неплохо водите.

처음 만든 것치고는 맛있어요.

Для первого раза вкусно.

이 가격치고는 품질이 훌륭해요.

Для такой цены качество отличное.

부모치고 자식 걱정 안 하는 사람 없어요.

Нет таких родителей, что не тревожились бы о детях.

📋 Краткое содержание

  • -치고 + отрицание — «все без исключения»
  • -치고(는) + оценка — «для такого-то, вопреки ожиданию»
  • Различать по сказуемому: 없다/안 — первое, похвала — второе
  • Присоединяется к существительному; глагол — через -(으)ㄴ/는 것치고
  • Форма 치고는 работает только во втором значении
