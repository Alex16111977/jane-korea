🎓 Korean Level System

Unlike the European system (A1, A2, B1, B2, C1, C2), Korea uses its own 6-level system (1급-6급):

1급 Elementary Alphabet, basic phrases
A1
2급 Basic Simple dialogues, grammar
A2
3급 Intermediate Everyday communication
B1
4급 Upper-Intermediate Advanced grammar
B2
5급 Advanced Fluent communication
C1
6급 Mastery Native-level proficiency
C2
