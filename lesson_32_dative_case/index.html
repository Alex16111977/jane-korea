Урок 7

Дательный падеж

🎯 Что такое дательный падеж?

Отвечает на вопрос "КОМУ?"

Показывает получателя действия

Кому даю? Кому говорю? Кому посылаю?

🎭 Три формы дательного падежа

에게

🤝 Стандартная вежливая форма

Нейтральная, подходит для большинства ситуаций

친구에게 (другу), 선생님에게 (учителю)

한테

😊 Неформальная разговорная форма

С близкими друзьями, младшими, в устной речи

엄마한테 (маме), 형한테 (старшему брату)

께

🙏 Очень вежливая почтительная форма

Для старших, уважаемых людей, официальных лиц

할아버지께 (дедушке), 사장님께 (боссу)

📖 Как выбрать форму?

👦

С равными/младшими

친구한테 (другу), 동생한테 (младшему брату/сестре)

👤

В нейтральных ситуациях

선생님에게 (учителю), 의사에게 (врачу), 직원에게 (сотруднику)

👴

С очень уважаемыми людьми

할머니께 (бабушке), 교수님께 (профессору), 사장님께 (директору)

Получатель 한테 (неформ.) 에게 (станд.) 께 (почтит.)
친구 (друг) 친구한테 친구에게 -
엄마 (мама) 엄마한테 엄마에게 어머니께
선생님 (учитель) - 선생님에게 선생님께
할아버지 (дедушка) - - 할아버지께
동생 (младший) 동생한테 동생에게 -

🎁 Давать подарки и вещи

친구에게 선물을 줘요 Другу подарок даю 친구 + 에게 (другу) + 선물을 (подарок) + 줘요 (даю)
동생한테 돈을 줬어요 Младшему брату/сестре деньги дал 동생 + 한테 (младшему) + 돈을 (деньги) + 줬어요 (дал)
할머니께 꽃을 드렸어요 Бабушке цветы подарил 할머니 + 께 (бабушке) + 꽃을 (цветы) + 드렸어요 (подарил - почтительно)

💬 Разговоры и общение

선생님께 질문했어요 Учителю вопрос задал 선생님 + 께 (учителю) + 질문했어요 (вопрос задал)
엄마한테 전화해요 Маме звоню 엄마 + 한테 (маме) + 전화해요 (звоню)
친구에게 비밀을 말했어요 Другу секрет рассказал 친구 + 에게 (другу) + 비밀을 (секрет) + 말했어요 (рассказал)

📮 Отправка и передача

지훈이에게 편지를 보냈어요 Чихуну письмо отправил 지훈이 + 에게 (Чихуну) + 편지를 (письмо) + 보냈어요 (отправил)
수진이한테 문자를 보내요 Суджин СМС отправляю 수진이 + 한테 (Суджин) + 문자를 (СМС) + 보내요 (отправляю)
사장님께 이메일을 보냈습니다 Директору имейл отправил 사장님 + 께 (директору) + 이메일을 (имейл) + 보냈습니다 (отправил - официально)

🤝 Помощь и услуги

민수한테 도움을 줬어요 Минсу помощь оказал 민수 + 한테 (Минсу) + 도움을 (помощь) + 줬어요 (оказал)
학생들에게 설명했어요 Студентам объяснил 학생들 + 에게 (студентам) + 설명했어요 (объяснил)
할아버지께 길을 안내해드렸어요 Дедушке дорогу показал 할아버지 + 께 (дедушке) + 길을 (дорогу) + 안내해드렸어요 (показал - почтительно)

💬 Мини-диалоги

А:
누구한테 선물을 사요?
Кому подарок покупаете?
Б:
여자친구에게 줄 거예요.
Девушке подарю.
А:
누구와 전화했어요?
С кем разговаривали по телефону?
Б:
어머니께 전화드렸어요.
Маме звонил.

⚠️ Важные нюансы

한테서 = ОТ кого-то (получил от...)
한테 = кому-то (дал кому-то)
께서 = уважительное "от" (от уважаемого лица)
께 = уважительное "кому" (уважаемому лицу)

친구한테서 편지를 받았어요 (от друга письмо получил)

할아버지께서 선물을 주셨어요 (дедушка подарок дал)

💪 Попробуй сам!

1. Как сказать "Другу книгу дал"?
Подсказка: 친구 + ? + 책을 + 줬어요
2. "Маме письмо отправлю" - какую форму выбрать?
Подсказка: 엄마 + ? + 편지를 + 보낼게요
3. В чем разница между "선생님에게" и "선생님께"?
4. "Бабушке цветы подарил" (очень вежливо) = ?
Ответы:
1. 친구한테 책을 줬어요 (또는 친구에게)
2. 엄마한테 편지를 보낼게요
3. 에게 = стандартная вежливость, 께 = особая почтительность
4. 할머니께 꽃을 드렸어요
