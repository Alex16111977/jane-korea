Урок 15

Неправильные глаголы ㄷ-неправильные

⚡ ㄷ-неправильные глаголы

ㄷ → ㄹ перед гласной

Основа на ㄷ + окончание на гласную = ㄷ меняется на ㄹ

Особая группа глаголов, которые изменяют основу перед гласными окончаниями

📚 Продолжаем изучать неправильные глаголы

📏 Обычные глаголы

먹다 → 먹어요, 먹었어요

Основа 먹 не меняется при добавлении окончаний

⚡ ㄷ-неправильные глаголы

듣다 → 들어요, 들었어요

Основа 듣 меняется на 들 перед гласными

📝 Правило изменения ㄷ

1

Основа на ㄷ + окончание на гласную

듣 + 어요 → ㄷ меняется на ㄹ

2

ㄷ исчезает, ㄹ присоединяется

듣다 → 듣 → 들 + 어요 → 들어요

3

С согласными ㄷ не меняется

듣다 + 습니다 → 듣습니다 (ㄷ остается)

🎯 Когда ㄷ меняется, а когда нет

Ключевое правило: смотрим на первую букву окончания!

✅ Окончание на ГЛАСНУЮ

ㄷ МЕНЯЕТСЯ на ㄹ

-어요, -았어요, -으면

듣다 → 들어요

❌ Окончание на СОГЛАСНУЮ

ㄷ НЕ МЕНЯЕТСЯ

-습니다, -지만

듣다 → 듣습니다

🎵 Слушать (듣다)

음악을 들어요 Слушаю музыку 듣다 → 듣 + 어요 → 들어요
노래를 들었어요 Слушал песню 듣다 → 듣 + 었어요 → 들었어요
라디오를 들으면서 공부해요 Учусь, слушая радио 듣다 → 듣 + 으면서 → 들으면서
블랙핑크 노래를 들어요 Слушаю песни BLACKPINK 듣다 → 들어요

🚶 Ходить (걷다)

공원에서 걸어요 Гуляю в парке 걷다 → 걷 + 어요 → 걸어요
학교까지 걸었어요 Дошел до школы пешком 걷다 → 걷 + 었어요 → 걸었어요
오늘 많이 걸어서 다리가 아파요 Сегодня много ходил, поэтому ноги болят 걷다 → 걸어서
같이 걸어요 Давайте вместе пойдем пешком 걷다 → 걸어요

❓ Спрашивать (묻다)

동생한테 물어보세요 Спросите у младшего брата/сестры 묻다 → 묻 + 어보세요 → 물어보세요
선생님께 물었어요 Спросил у учителя 묻다 → 묻 + 었어요 → 물었어요
질문을 물어도 돼요? Можно задать вопрос? 묻다 → 물어도

📦 Грузить и другие действия

짐을 트럭에 실었어요 Погрузил вещи в багажник машины 싣다 → 싣 + 었어요 → 실었어요
이해하지 못해요 Не понимаю 깨닫다 → 깨달 + 아요 → 깨달아요

📏 С согласными (ㄷ НЕ меняется)

음악을 듣습니다 Слушаю музыку (формально) 듣다 + 습니다 → 듣습니다 (ㄷ не меняется)
듣지만 이해 못해요 Слушаю, но не понимаю 듣다 + 지만 → 듣지만 (ㄷ не меняется)
음악을 듣지 않아요 Не слушаю музыку 듣다 + 지 않아요 → 듣지 않아요
걷거나 뛰거나 해요 Хожу или бегаю 걷다 + 거나 → 걷거나 (ㄷ не меняется)

⚠️ Исключения из правила!

НЕ все глаголы на ㄷ - неправильные!

❌ Эти глаголы НЕ меняются:

닫다 (закрывать) → 닫아요 (НЕ 달아요)

받다 (получать) → 받아요 (НЕ 랄아요)

믿다 (верить) → 믿어요 (НЕ 밀어요)

묻다 (хоронить) → 묻어요 (НЕ 물어요)

💡 Эти исключения нужно запомнить отдельно!

❌ Примеры исключений

동생이 문을 닫았어요 Младший брат закрыл дверь 닫다 → 닫았어요 (исключение, ㄷ не меняется)
돈을 받았어요 Получил деньги 받다 → 받았어요 (исключение)
친구를 믿어요 Верю другу 믿다 → 믿어요 (исключение)
어제 강아지를 묻었어요 Вчера похоронил собаку 묻다 (хоронить) → 묻었어요 (исключение)

💪 Потренируемся!

1. Как сказать "Слушал классическую музыку"?
Подсказка: 듣다 + 었어요
2. "Вчера много ходил" = ?
Подсказка: 걷다 + 었어요
3. Почему 받다 → 받아요, а не 랄아요?
4. В чем разница между 묻다 (спрашивать) и 묻다 (хоронить)?
Ответы:
1. 클래식 음악을 들었어요
2. 어제 많이 걸었어요
3. 받다 - исключение из ㄷ-неправильного правила
4. 묻다 (спрашивать) = ㄷ-неправильный → 물어요; 묻다 (хоронить) = исключение → 묻어요

📝 Главное правило!

ㄷ-неправильные: ㄷ → ㄹ перед гласными

Гласное окончание: ㄷ → ㄹ (듣다 → 들어요)

Согласное окончание: ㄷ остается (듣다 → 듣습니다)

Исключения: 닫다, 받다, 믿다, 묻다 (хоронить)

Внимание на исключения - они НЕ следуют правилу!
