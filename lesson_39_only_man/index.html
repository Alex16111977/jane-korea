Частица "только" - 만

🎯 Что такое 만?

Выражает ограничение или исключительность

"Только" или "Лишь"

Показывает, что действие касается только чего-то одного!

📝 Формула использования

💡 Основное правило

существительное + 만

물만 (только воду)

저만 (только я)

🎯 Значение

만 = только

Ограничение, исключительность

"Не что-то другое, а только это"

👥 Люди с частицей 만

✅❌ Правила сочетания с другими частицами

✅ МОЖНО сочетать

만을 - только (что-то) винительный

만이 - только (кто-то) именительный

만에게 - только (кому-то)

만에서 - только (где-то)

만까지 - только до

❌ Особенности

만은/만는 - редко, лучше избегать

Обычно 만 используется само по себе

만 чаще заменяет основные частицы

📊 만 vs 도 - сравнение

Значение 만 (только) 도 (тоже) Различие
Ограничение 물만 마셔요 물도 마셔요 только воду / воду тоже
Люди 저만 왔어요 저도 왔어요 только я пришёл / я тоже пришёл
Количество 하나만 주세요 하나도 주세요 только одну / одну тоже дайте
Время 5분만 기다려요 5분도 기다려요 только 5 минут / 5 минут тоже

🏠 Место и локация

집에서만 공부해요 Только дома учусь 집 + 에서만 (только дома) + 공부해요 (учусь)
수진이는 도서관에서만 책을 읽어요 Суджин только в библиотеке книги читает 수진이는 (Суджин) + 도서관에서만 (только в библиотеке) + 책을 읽어요 (книги читает)
한국에서만 살고 싶어요 Только в Корее хочу жить 한국 + 에서만 (только в Корее) + 살고 싶어요 (хочу жить)

🎯 Действия и ограничения

영화만 봐요 Только фильмы смотрю 영화만 (только фильмы) + 봐요 (смотрю)
민호는 게임만 해요 Минхо только в игры играет 민호는 (Минхо) + 게임만 (только в игры) + 해요 (играет)
한국어만 공부하고 있어요 Только корейский изучаю 한국어만 (только корейский) + 공부하고 있어요 (изучаю)

⚠️ Важные особенности частицы 만

1. Ограничение: 만 показывает, что больше ничего нет
물만 마셔요 = пью только воду (и больше ничего)
저만 왔어요 = пришёл только я (больше никто)
2. Сочетание: 만 может сочетаться с падежными частицами
만을, 만이, 만에게, 만에서 ✅
3. Различие с 도:
만 = исключительность (только это)
도 = дополнение (это тоже)

💪 Проверь себя!

1. Как сказать "Только кофе пью"?
커피 + ? + 마셔요 = ?
2. "Только 5 минут подождите" = ?
5분 + ? + 기다려 주세요 = ?
3. В чем разница: "물만 마셔요" vs "물도 마셔요"?
4. "Только дома учусь" = ?
집 + ? + 공부해요 = ?
Ответы:
1. 커피만 마셔요
2. 5분만 기다려 주세요
3. 만 = только воду (ничего больше), 도 = воду тоже (плюс что-то ещё)
4. 집에서만 공부해요

🎯 Главное правило!

만 = только, лишь

존재 + 만 = ограничение, исключительность
Сочетается: 만을, 만이, 만에게, 만에서
Противоположность 도 (тоже)

물만 • 저만 • 5분만 • 집에서만
