Урок 11: Временные конструкции

⏰ Что мы изучаем

Сегодня мы изучим продвинутые временные конструкции корейского языка, которые используются для выражения сложных временных отношений:

  • -(으)ㄹ 때 — когда (в момент действия)
  • -는 동안 — в течение, пока
  • -자마자 — как только, сразу после
  • -(으)ㄴ 지 — с тех пор как (прошедшее время)

📚 Грамматическое объяснение

🔑 Временные конструкции

Корейский язык обладает богатым набором грамматических конструкций для выражения временных отношений между действиями. Каждая конструкция передаёт свой оттенок — одновременность, последовательность, мгновенность или длительность.

1. -(으)ㄹ 때 — когда

Конструкция -(으)ㄹ 때 означает "когда" и указывает на момент совершения действия. Присоединяется к основе глагола.

Согласная основа + 을 때

Если основа глагола оканчивается на согласную:

먹다 (есть) → 먹 + 을 때 = 먹을 때 (когда ем/буду есть)

읽다 (читать) → 읽 + 을 때 = 읽을 때 (когда читаю)

Гласная основа + ㄹ 때

Если основа глагола оканчивается на гласную:

가다 (идти) → 가 + ㄹ 때 = 갈 때 (когда иду)

보다 (смотреть) → 보 + ㄹ 때 = 볼 때 (когда смотрю)

Прошедшее время: -았/었을 때

먹다 → 먹었을 때 (когда ел)

가다 → 갔을 때 (когда ходил)

Для прошедшего времени добавляем -았/었 перед -을 때

2. -는 동안 — в течение, пока

Конструкция -는 동안 означает "в течение", "пока" и указывает на период времени, в течение которого происходит другое действие. Присоединяется к основе глагола.

Образование: основа глагола + 는 동안

기다리다 (ждать) → 기다리 + 는 동안 = 기다리는 동안 (пока жду)

잠자다 (спать) → 잠자 + 는 동안 = 잠자는 동안 (пока сплю)

공부하다 (учиться) → 공부하 + 는 동안 = 공부하는 동안 (пока учусь)

Просто: основа глагола + 는 동안 (для всех глаголов)

3. -자마자 — как только

Конструкция -자마자 означает "как только", "сразу после" и указывает на мгновенную последовательность двух действий. Второе действие происходит немедленно после первого.

Образование: основа глагола + 자마자

도착하다 (прибыть) → 도착하 + 자마자 = 도착하자마자 (как только прибыл)

일어나다 (встать) → 일어나 + 자마자 = 일어나자마자 (как только встал)

끝나다 (закончиться) → 끝나 + 자마자 = 끝나자마자 (как только закончилось)

Просто: основа глагола + 자마자 (для всех глаголов, без исключений)

4. -(으)ㄴ 지 + время — с тех пор как

Конструкция -(으)ㄴ 지 используется для выражения времени, прошедшего с момента действия. После неё обычно идёт указание на длительность и глагол 되다 или 지나다.

Согласная основа + 은 지

먹다 (есть) → 먹 + 은 지 = 먹은 지

읽다 (читать) → 읽 + 은 지 = 읽은 지

Гласная основа + ㄴ 지

오다 (приходить) → 오 + ㄴ 지 = 온 지

배우다 (учить) → 배우 + ㄴ 지 = 배운 지

한국에 온 지 3년 됐어요. — Прошло 3 года с приезда в Корею.

📝 Примеры использования

협상이 결렬될 때를 대비해 대안을 미리 마련해 두어야 한다.

Нужно заранее подготовить альтернативный план на случай, если переговоры сорвутся.

-(으)ㄹ 때 — указание на момент действия

조사가 진행되는 동안 관련 시설의 운영이 전면 중단되었다.

Пока шло расследование, работа соответствующего объекта была полностью приостановлена.

-는 동안 — в течение периода действия

신제품이 출시되자마자 매장 앞에 긴 줄이 늘어섰다.

Как только новый продукт поступил в продажу, у магазина выстроилась длинная очередь.

-자마자 — мгновенная последовательность

이 정책이 시행된 지 채 1년도 되지 않아 부작용이 속출하고 있다.

Не прошло и года с момента введения этой политики, а побочные эффекты уже проявляются один за другим.

-(으)ㄴ 지 — время с момента действия

📋 Краткое содержание

  • -(으)ㄹ 때 — когда (в момент действия): 먹을 때, 갈 때
  • -는 동안 — в течение, пока: 기다리는 동안, 잠자는 동안
  • -자마자 — как только: основа + 자마자 (도착하자마자)
  • -(으)ㄴ 지 — с тех пор как: 온 지 3년 됐어요
  • Каждая конструкция выражает свой тип временных отношений
