Выражение желания 고 싶다

💫 Что такое 고 싶다?

Выражает желание что-то ДЕЛАТЬ

"Хочу + действие"

Хочу есть, хочу пить, хочу идти, хочу спать!

🎯 Простая формула

глагол + 고 싶다

⚡ Основа + желание

먹다 (есть) + 고 싶다 = 먹고 싶다 (хочу есть)

가다 (идти) + 고 싶다 = 가고 싶다 (хочу идти)

먹다 (есть)
먹고 싶다
хочу есть
보다 (смотреть)
보고 싶다
хочу увидеть
자다 (спать)
자고 싶다
хочу спать
배우다 (учиться)
배우고 싶다
хочу учиться
놀다 (играть)
놀고 싶다
хочу играть
쉬다 (отдыхать)
쉬고 싶다
хочу отдохнуть

🎭 Спряжение по формам вежливости

Стиль Форма Пример Перевод
Неформальный 고 싶어 먹고 싶어 хочу есть
Вежливый 고 싶어요 먹고 싶어요 хочу есть
Официальный 고 싶습니다 먹고 싶습니다 хочу есть

🍽️ Еда и напитки

지민이는 피자를 먹고 싶어요 Чимин хочет есть пиццу 지민이는 (Чимин) + 피자를 (пиццу) + 먹고 싶어요 (хочет есть)
수연이가 커피를 마시고 싶어해요 Суён хочет пить кофе 수연이가 (Суён) + 커피를 (кофе) + 마시고 싶어해요 (хочет пить)
민수는 아이스크림을 먹고 싶어 Минсу хочет есть мороженое 민수는 (Минсу) + 아이스크림을 (мороженое) + 먹고 싶어 (хочет есть - неформ.)

🎬 Развлечения и хобби

혜진이는 영화를 보고 싶어요 Хеджин хочет смотреть фильм 혜진이는 (Хеджин) + 영화를 (фильм) + 보고 싶어요 (хочет смотреть)
태형이가 게임을 하고 싶어해요 Тэхён хочет играть в игры 태형이가 (Тэхён) + 게임을 (игры) + 하고 싶어해요 (хочет играть)
우리는 노래방에 가고 싶어요 Мы хотим идти в караоке 우리는 (мы) + 노래방에 (в караоке) + 가고 싶어요 (хотим идти)

⚠️ Важная особенность!

О себе: 고 싶어요
О других: 고 싶어해요 (добавляется 하다)
Примеры:
나는 가고 싶어요 (я хочу идти)
지민이는 가고 싶어해요 (Чимин хочет идти)
Почему так?
고 싶다 - это субъективное состояние.
О чужих желаниях мы можем только предполагать!

🚫 Отрицание: НЕ хочу

가고 싶지 않아요 НЕ хочу идти 가다 (идти) + 고 싶지 않아요 (не хочу)
공부하고 싶지 않아 не хочу учиться (неформально) 공부하다 (учиться) + 고 싶지 않아 (не хочу)
일하고 싶지 않습니다 не хочу работать (официально) 일하다 (работать) + 고 싶지 않습니다 (не хочу)

💪 Проверь себя!

1. Как сказать "хочу спать"?
자다 + 고 싶다 = ?
2. "Минджи хочет учить корейский" = ?
민지는 + 한국어를 + ?
3. В чем разница: "가고 싶어요" vs "가고 싶어해요"?
4. "Не хочу работать" (вежливо) = ?
Ответы:
1. 자고 싶어요 (хочу спать)
2. 민지는 한국어를 배우고 싶어해요
3. 고 싶어요 = о себе, 고 싶어해요 = о других
4. 일하고 싶지 않아요

🌟 Главное правило!

고 싶다 = хочу ДЕЛАТЬ

О себе: 먹고 싶어요 ✅
О других: 먹고 싶어해요 ✅
Отрицание: 먹고 싶지 않아요 ✅

Теперь ты можешь выражать любые желания! 💫
